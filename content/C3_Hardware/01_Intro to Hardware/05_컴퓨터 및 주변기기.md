## 1. 컴퓨터의 구성
- **하드웨어**(Hardware): 컴퓨터를 구성하는 **기계적 장치**
- **소프트웨어**(Software): 하드웨어의 동작을 지시하고 제어하는 **명령어의 집합**
- 하드웨어 구성: (산술논리)연산장치 **ALU**, 제어장치, 레지스터 / 기억장치 / 입력장치 / 출력장치

## 2. CPU (Central Processing Unit)

### 2.1. CPU의 구성
> CPU는 다음 3가지 주요 기능을 갖는 논리회로의 블록으로 구성된다.

1. **제어장치**(Control Unit)
	- 명령어를 순서대로 실행할 수 있도록 제어하는 장치 → ==CPU 내부의 CPU==
2. **연산장치**(ALU: Arithmetic & Logic Unit)
	- 덧셈/뺄셈/곱셈/나눗셈 등의 **산술연산**, 논리 곱/합/부정 등의 **논리연산**만을 전문적으로 수행
3. **레지스터**(Register)
	- CPU 내부의 초고속 기억장치로 명령어 주소, 명령어 코드, 연산에 필요한 데이터, 연산 결과 등을 임시 저장
	- **플립플롭**(Flip-flop) 소자로 구성되어 매우 빠르다.
	- 외부 프로그램이 사용 가능한 **범용 레지스터**와 CPU만 사용 가능한 **특수 레지스터**로 구분

### 2.2. 명령어 사이클 (Instruction Cycle)
- 기계어(명령어) 하나는 CPU 내부에서 실행될 때 몇 개의 단계로 구분되어 처리된다. (**CPU마다 단계의 숫자가 다르다**)
- ==전원이 공급되면 명령어 사이클이 시작되고, 전원이 꺼질 때까지 **무한 반복** 실행된다.==

1. **인출(Fetch) 단계**
	- **PC**(프로그램 카운터) 레지스터에 지정된 주소의 주기억장치에서 명령어를 인출하여 CPU 내부의 **IR**(Instruction Register, 명령어 레지스터)에 저장
	- 다음 순서의 명령어를 인출하기 위해 **PC값을 자동으로 증가**시킴
2. **실행(Execution) 단계**
	- IR에 저장된 명령어를 **해독**하고, 그 결과에 따라 필요한 제어 신호들을 차례로 발생시켜 명령어를 실행
	- 방식: 마이크로 프로그램 제어방식(CISC) vs 고정배선 제어방식(RISC)
3. **인터럽트(Interrupt) 단계**
	- 단계 구분의 숫자에는 포함되지 않지만 ==**모든 CPU마다 이 단계가 있다.**==
	- 현재 실행 중인 프로그램보다 **더 우선적으로 처리할 일이 있는지** 체크하는 단계

- **인터럽트**(Interrupt): CPU가 명령어를 수행하는 동안 시스템의 내·외부에서 발생하는 **예기치 못한 사건**
	- 컴퓨터/임베디드 시스템에서는 이 기능을 거의 모든 **입출력 기능**에 사용하며 매우 효율적이다.
	- **절차**
		1. 인터럽트 발생을 검출
		2. 현재 진행 중이던 프로그램의 수행을 중단
		3. 요청된 인터럽트를 처리하기 위한 프로그램을 먼저 수행
		4. 다시 돌아와 진행 중이던 나머지 명령어들을 수행

## 3. 기억장치

### 3.1. CPU, ROM, RAM, 보조기억장치의 관계
1. 컴퓨터 전원을 켜면 CPU는 자동적으로 **ROM**에 저장된 프로그램을 실행시켜 **부팅**을 수행한다.
2. 부팅이 되면 사용자(운영체제)는 **보조기억장치**의 응용 프로그램을 실행시켜 **RAM**에 명령들을 적재한다.
3. CPU는 RAM에서 실행할 명령어/데이터를 가져와 처리하고 결과는 다시 RAM에 저장한다.
4. 모든 처리가 완료되면 RAM에 저장된 결과들이 보조기억장치에 저장된다.

### 3.2. 주기억장치
- CPU가 실행할 프로그램과 데이터가 저장되는 기억장치
- ==CPU가 세부 내용 모두를 **시스템버스를 통해 직접 접근** 가능==
- 크기가 작고, 속도가 빠르며, 전력소모가 작다.

- **RAM** (Random Access Memory)
	- **휘발성** → 전원 공급이 중단되면 기억된 내용이 소멸
	- 자유롭게 읽고 임의로 기억시킬 수 있음
	- 종류: SRAM, DRAM, VRAM
- **ROM** (Read Only Memory)
	- **비휘발성** → 전원이 중단되어도 내용이 소멸되지 않음
	- 읽을 수는 있지만 임의로 기억시킬 수 없음
	- 컴퓨터 전원을 켰을 때 최초로 시작되는 **부트(Boot) 프로그램** 등이 주로 탑재
	- ==HDD를 사용하지 않는 임베디드 시스템에서는 **모든 프로그램이 ROM에 위치**==
	- 기록 횟수와 저장 방식에 따라 Mask ROM, PROM, EPROM, EEPROM으로 구분
	- 근래에는 **플래시 메모리**로 대체되는 추세

- **DRAM vs SRAM**

| | **DRAM** (동적) | **SRAM** (정적) |
|---|---|---|
| 구성 | **커패시터**에 전하를 충전해 정보 기억 (매우 간단한 구조) | 논리회로 부품인 **플립플롭**으로 구성 |
| 재충전 | 방전 방지를 위해 **Refresh 회로** 내장 | 재충전 기능이 **필요 없음** |
| 속도/가격 | 느림 / 쌈 | 매우 빠름 / 비쌈 |
| 용도 | 구조가 간단해 **대용량에 적합**, PC의 RAM | 캐시메모리, PC에서 사용자가 직접 쓰는 경우는 없음 |

### 3.3. 보조기억장치
- 주기억장치의 제한된 용량을 지원하는 장치
- ==CPU가 시스템 버스를 통해 모든 주소를 **직접 접근하는 것이 불가능** → 별도의 입출력 방식 사용==

#### 3.3.1. HDD (Hard Disk Drive)
- 자화(magnetization)될 수 있는 물질로 코팅된 플라스틱이나 금속의 **원형 평판**을 밀봉해 만든 저장장치
- 근래에는 주 디스크로 SSD, 보조 디스크로 HDD를 사용하는 추세

- **내부 구조**
	1. **원형 평판**(circular platter, 플래터): 정보가 저장되는 장소로 다수의 **트랙**으로 구성, 일반적으로 양면 사용
	2. **헤드**(head): 전도성 코일로 표면을 자화시켜 데이터를 저장하고, 반대로 자화 상태를 읽어 디지털 정보로 변환
	3. **디스크 팔**(disk arm): 헤드를 이동시키는 장치
	4. **구동장치**(actuator): 원형 평판 회전 및 디스크 암 구동을 위한 모터

- **주요 용어**
	- **트랙**(Track): 동심원들로 나누어지는 기억 공간
		- ==헤드의 위치가 동일한 모든 트랙 = **실린더**(Cylinder)==
	- **섹터**(Sector): 트랙 내부에 구성되는 **최소 단위**의 저장 공간, 512바이트 또는 4K바이트 단위
	- **Disk 용량 계산**: 헤드 수 × (트랙 수/디스크) × (섹터 수/트랙) × 섹터 크기
		- *Kilo 단위를 1,024가 아닌 **1,000**으로 계산*

- **종류**
	- 크기: 3.5"(데스크톱), 2.5"(노트북·외장하드), 1.8"(Palm PC)
	- 속도(**RPM**: Rotation Per Minute)
		- 10,000RPM: 고속용이나 소음이 많고 전력소모가 높음
		- 7,200RPM: 일반적으로 많이 사용
		- 5,400RPM: 노트북, NAS 등 데이터 전용 저장장치
	- **Disk Buffer**: 동작이 느린 HDD 내부에 사용되는 메모리 버퍼(일종의 캐시), 32MB 또는 64MB

#### 3.3.2. 광 디스크 (ODD: Optical Disk Drive)
- 디지털로 저장된 데이터에 **레이저**를 쏘여 반사되는 내용(광센서)으로 정보를 판독
- **등선속도**를 이용하며, 모든 트랙은 **나선형으로 하나로 연결**된다.
- 짧은 레이저 파장을 이용하여 집적밀도를 향상시켰다. (CD-ROM → DVD → BD)
- CD-R은 **염료(색채)층**, CD-RW는 반복저장이 가능한 **기록층의 위상(반사도 변화)**을 레이저로 바꿔주는 것

| | **CD-ROM** | **DVD** | **BD** (Blu-ray) |
|---|---|---|---|
| 디스크 지름/두께 | 120mm / 1.2mm | ← | ← |
| 디스크 구조 | 단층 | 2층 (0.6mm×2) | ← |
| **레이저 파장** | 720nm | 650nm (red) | **405nm (blue)** |
| 데이터 용량 | 680MB | 단층 4.7GB / 복층 8.5GB | 단층 25GB / 복층 50GB |
| 1x 배속 속도 | 0.15MB/s | 1.32MB/s | 4.5MB/s |

#### 3.3.3. 플래시 메모리 (Flash Memory)
- **높은 저장 밀도**: 한 개의 트랜지스터에 하나 또는 복수 비트의 정보를 저장
	- *참고: EEPROM은 비트 당 두 개의 트랜지스터*
- 낮은 전력소모량, 높은 신뢰성, 속도 향상
- **부동게이트** 내에 존재하는 전자의 존재 여부(SLC) 또는 수량(MLC, TLC) 등으로 판독 → **터널링 효과**
- *Cell = 기억장치에서 한 비트를 저장하는 최소 단위*

- **종류**
	- **NOR Flash**: Cell끼리 **병렬**연결, **셀 단위** 읽기/쓰기(빠름), 비싸다
	- **NAND Flash**: Cell끼리 **직렬**연결, **블록 단위** 읽기/쓰기(느림), 싸다 → ==많이 사용된다==

- **NAND Flash의 셀 종류**

| 특성 | **SLC** (Single) | **MLC** (Multi) | **TLC** (Triple) |
|---|---|---|---|
| Cell당 저장 Bit 수 | 1 | 2 | 3 |
| 읽기/쓰기/삭제 시간 | 빠르다 | 중간 | 느리다 |
| 재기록 가능 횟수 | 100,000 | 3,000~10,000 | 1,000 |
| 집적도 | 저 | 중 | 고 |
| 가격 | 고 | 중 | 저 |

- *최근에는 **QLC**(Quad-Level Cell, 4비트/셀)가 보급 중이다.*

- **응용 제품**
	1. **SSD**(Solid State Drive): HDD 대용, MLC/TLC NAND Flash, SATA-3(6Gbps) 또는 NVMe(PCIe) I/F
	2. **USB 메모리**: SLC/MLC/TLC, USB 3.0(5Gbps), USB 3.1(10Gbps)
	3. **SD 카드**(Secure Digital Card): SD/Mini SD/Micro SD, SDHC(FAT32, ~32GB)·SDXC(exFAT, 32GB~), Class(C10=10MB/s), UHS
	4. **메모리 스틱**(Sony 자사 제품용), **CF**(Compact Flash) — 주로 DSLR 카메라에 사용

- **SSD 주요 용어**
	- **마모 평준화**(wear leveling): 삭제·쓰기가 일부 블록에 집중되면 수명이 단축되므로, 덜 사용된 블록으로 데이터를 저장해 **각 블록을 고르게 사용**
	- **쓰레기 수집**(garbage collection): 마모 평준화 시 수정된 내용을 다른 페이지에 쓰고 삭제하지 않은 페이지가 많아지면 블록 단위로 삭제하는 작업 → **TRIM 기능**(OS 지원)
	- **초과 대비공간**(over-provisioning): 마모 평준화 작업용으로 필요한 여유 공간

## 4. 입력 장치
> 최근에는 대부분의 유선 입력장치가 **USB** 방식으로 컴퓨터와 통신한다.

### 4.1. 키보드
- 사용자의 Text 정보를 컴퓨터에 입력시키는 장치
- 자판 배열에 따라 쿼티, 드보락 등으로 분류하며, ==**104개의 키를 갖는 QWERTY 방식**이 ANSI 표준==
- 유선: PS2, USB / 무선: IR, RF(2.4GHz), 블루투스 → 본체에 **USB 동글**을 사용해 인터페이스
- **모바일 기기 자판**: 크기가 작아 **가상(Virtual) 키보드**를 사용, 휴대전화에서는 천지인방식·이지한글방식

- *참고: **동글**(Dongle) — 외부 주변장치 기능 확장을 위해 컴퓨터 입출력 포트에 꽂는 장치*
	- *주로 USB 포트에 꽂아 사용하며, 크롬캐스트 등은 HDMI 포트에 연결*
	- *노트북처럼 확장슬롯이 없는 경우 매우 유용 (유선랜, 무선랜, R/F, 블루투스, 사운드 카드 등)*

### 4.2. 마우스
- 초기 제품의 모양이 쥐(mouse)를 닮아 마우스라 부른다.
- **구동 원리에 따른 분류**
	- **볼 마우스**: X축과 Y축의 움직임을 감지하는 두 개의 휠이 있어 **단위 시간당 회전수**를 이동거리로 환산
	- **광 마우스**: 소형 광학센서와 LED 사용, 볼마우스보다 **민감도가 증가**하여 포인터 이동이 부드럽다
		- ==단점: 광선을 바닥에 비추므로 **유리 표면이나 코팅이 두꺼운 가구 표면에서는 동작이 안 됨**==
- **인터페이스**: 유선(PS2, USB) / 무선(RF 2.4GHz, 블루투스)

### 4.3. 기타 입력 장치
- **조이스틱**(Joystick): 360도 자유롭게 움직이는 스틱을 이용, 누르는 **압력을 단계적으로 인식**. 최근에는 **진동기능(햅틱)**을 내장
- **디지타이저**(Digitizer): **펜**의 개념을 컴퓨터에 활용한 입력장치
	- 그림, 설계 도면, 필기체 문자 등의 아날로그 정보를 디지털로 변환하며, **평면 태블렛과 전자펜**으로 구성
	- 특히 모바일 기기에서 편리한 인터페이스로 사용 (삼성 노트 시리즈)
- **스캐너**(Scanner): 텍스트, 그림, 사진 등의 영상 자료를 컴퓨터로 읽어 들이는 입력 장치 (핸드/탁상용)
	- **바코드·QR코드 판독기**: 빛을 쏘아 인쇄된 코드를 인식, POS 시스템에서 많이 사용
		- **QR 코드** = Quick Response Code의 약자인 **2차원** 바코드 체계
	- **3D 스캐너**: 레이저 빔으로 물체 외곽선의 좌표 값을 추출해 3차원 데이터를 획득
		- **접촉식**: 대상물의 표면과 직접 접촉하여 센서의 상대 이동 값으로 획득
		- **비접촉식**: 광학적 이미지 처리를 통해 획득
		- 3D 프린터로 물건을 만들려면 먼저 3D 스캐너로 형상 정보를 만든다.
- **디지털 카메라 / 웹 캠**: 피사체의 영상을 필름 대신 **전자촬영소자**에 기록하여 반도체 메모리에 저장
	- 주로 **CMOS 방식**의 이미지 센서를 사용하며, USB로 인터페이스된다.

## 5. 출력 장치
> 최신 컴퓨터용 출력장치들은 (영상출력장치를 제외하고) 대부분 USB로 통신한다.

### 5.1. 영상출력장치
- 크게 **그래픽 카드**와 **디스플레이 장치**로 구분된다.
- 둘 사이에는 다양한 인터페이스 표준이 있다. (RGB, DVI, HDMI, DP)

#### 5.1.1. 디스플레이 주요 용어
1. **해상도**(Resolution): 화면에 몇 개의 화소가 표시되는지의 표기법 (예: **FHD** = 1920×1080)
	- 영문 표기법은 **VESA**라는 단체에서 규정 (비디오·멀티미디어 장치의 표준화 추진)
2. **픽셀**(Pixel): 화소의 수. ==칼라에서는 **하나의 픽셀이 R, G, B 3개의 dot**로 구성==
3. **ppi**(Pixel per inch): 대각선 1인치 당 몇 개의 픽셀이 있는지를 표시하는 단위
4. **응답속도**(Response time): 액정이 움직이는 시간 (수~수십 ms) → 빠른 동영상에서 **화면 끌림** 발생
	- ==**계조간(Gray-to-Gray) 응답속도**가 화면 끌림에 매우 민감==
	- **OLED는 응답속도가 0ms**
5. **시야각**(Viewing Angle): 화면의 색상이 왜곡(색반전)되지 않는 각도 범위
	- OLED > 광시야각 액정 모드(VA, IPS) > TN 액정모드
6. **명암비**(C/R: Contrast Ratio) = White 휘도 / Black 휘도
	- 가장 어두운 화면 대비 가장 밝은 화면의 비율. 높으면 머리카락이 한 올씩 구분된다.
7. **색재현율**: 디스플레이에서 색을 표현할 수 있는 능력의 수치 (NTSC 기준 면적 %)
	- CRT 모니터가 색재현율 100%(NTSC 규격). 높을수록 넓은 범위의 색을 표현할 수 있다.
8. **Color Depth**(색심도): 1개의 픽셀에서 표현할 수 있는 색의 수
	- RGB 각 8비트 → 24비트 색심도 (각각 $2^8$ = 0~255 종류)
	- ==**24비트 색심도 = 트루칼라**(True Color)== — 훈련받지 않은 일반 사람이 구별할 수 있는 최대 범위
	- 고급 TV: 30비트(10비트×RGB) 또는 36비트(12비트×RGB)
9. **잔상**: 동일한 픽셀이 오랫동안 켜지면 경시변화로 비정상적인 색상을 나타내는 현상 → **OLED가 심함**

#### 5.1.2. 모니터 입력 인터페이스
1. **RGB**(D-sub = VGA): **아날로그** 방식, 잡음이 많이 발생해 거의 사용 안 함
2. **DVI**(Digital Visual Interface): 4쌍의 연선으로 디지털 영상 데이터 전달, **차동신호**로 안정적·빠른 전송
3. **HDMI**(High Definition Multimedia Interface): ==DVI에 **음성신호**까지 포함한 규격==, 버전에 따라 지원 해상도·기능이 달라짐
4. **DP**(Display Port): **로열티를 지불하지 않기 위해** PC 업체들이 만든 최신 규격

#### 5.1.3. 그래픽 카드
- 컴퓨터에서 만들어진 이미지를 모니터와 연결시켜 주는 하드웨어
- **구조**
	1. **GPU**(Graphics Processing Unit): 3D 그래픽 처리 능력을 갖추어 **CPU에 부담을 주지 않으면서** 고품질 3D 그래픽 구현 (엔비디아 지포스, AMD 라데온)
	2. **비디오 메모리(VRAM)**: GPU가 처리하는 그래픽 데이터의 임시 저장
	3. PCB 기판 / 4. 장착 슬롯(컴퓨터의 버스와 연결) / 5. 모니터 출력부
	6. 쿨러 / 7. 보조 전원 공급용 포트
- *일부 인텔 CPU는 그래픽 카드의 기능을 CPU와 칩셋에서 제공해 준다.*

#### 5.1.4. 디스플레이 장치의 종류
> **FPD**(Flat Panel Display, 평판 디스플레이) — ※ **CRT는 평판 디스플레이가 아님**

- **E-Paper**: **반사 빛**을 이용한 저소비전력 디스플레이 (e-book)
- **LCD**(Liquid Crystal Display, 액정 디스플레이)
	- 인가된 전압에 따라 **액정의 방향이 움직여** 빛을 투과 또는 차단
	- 모든 Dot에 별도의 전압을 가해 투과 정도를 결정 (전압에 따라 투과도도 가변)
	- ==패널 **뒤에는 백라이트**(흰색 빛), 패널 **앞에는 칼라필터**(R, G, B 색상)가 필요==
	- **STN LCD**: 표시품질이 나쁨, 저가형
	- **TFT LCD**: TN(시야각이 나빠 저가형) / 광시야각(VA, IPS — 고급형)
- **OLED**(Organic Light Emitting Diode, 유기 발광 다이오드)
	- 유기물질에 전류가 흐르면서 **스스로 빛을 내는 자체발광** 다이오드
	- ==**백라이트가 필요 없어** 패널 모듈이 얇고 가벼워지며, **휘어지는(Flexible)** 패널이나 투명 패널 제작 가능==
	- 주로 능동형 구동방식(**AMOLED**)을 사용 (↔ PMOLED: 줄 단위로 픽셀 관리)
	- RGB OLED(삼성)와 White OLED(LG TV) 방식
- **QD**(Quantum Dot): 나노 입자, 다양하고 안정적인 색의 발광/형광

> ※ **발광**은 스스로 빛을 내는 것, **형광**은 빛을 받아 변형하는 것

### 5.2. 인쇄장치
- **도트 매트릭스 프린터**(Dot Matrix)
	- 헤드에서 전기적 신호에 따라 복수개의 **핀들이 튀어나와** 잉크 리본이나 먹지를 누르며 인쇄
	- 근래의 응용: 잉크 캡슐 내장형 종이(신용카드 영수증), **열 감응 종이 + 열전사 헤드**(번호표, 영수증)
- **잉크젯 프린터**(Ink-Jet)
	- 프린터 헤드의 미세한 구멍들이 **잉크 방울을 뿜어** 인쇄하는 방식
	- 열을 가해 잉크를 녹여 출력하는 **열 전사방식**도 사용
	- 최근 반도체/디스플레이 산업에서 적용 연구가 많다.
- **레이저 프린터**(Laser)
	- **복사기의 인쇄방식과 유사**
	- 롤러 모양의 **드럼**에 인쇄할 모양을 감광한 후 **토너**를 묻히고, 종이를 밀착해 **열과 압력**으로 옮겨 붙임
- **3D 프린터**
	- 3D 스캐너 또는 3D 모델링 프로그램으로 만든 3차원 도면을 기반으로 실물의 입체 모양을 만드는 기계
	- **4차 산업혁명**의 한 축이라 불릴 정도로 중요하게 여겨진다.
	- **적층형**: 파우더, 플라스틱 액체·실 등을 얇은 층으로 겹겹이 쌓아 형상 제작
	- **절삭형**: 덩어리를 조각하듯이 깎아내 형상 제작
- **플로터**(Plotter): 그림이나 설계 도면을 인쇄하는 장치로 주로 **CAD**의 출력 장치로 이용, **용지 크기에 제한받지 않음**
- **마이크로 필름(COM) 출력 장치**: 처리한 자료를 종이나 화면이 아닌 마이크로 필름에 수록

### 5.3. 음향 장치
- 이어폰, 헤드폰, 스피커 등
- **홈시어터 시스템**에서는 **5.1 채널** 스피커가 사용된다.
	- 2개의 전방 + 2개의 후방 + 음성 출력 중앙 스피커 + 중저음 보강용 **우퍼**(Woofer) = 5+1 = 6개
	- 최근에는 6.1채널, 7.1채널 등도 사용

### 5.4. 촉각 장치 (Haptic Device)
- 시각 및 청각 이외의 **촉각**을 표현하기 위한 출력 장치
- 촉감, 진동 또는 압력 등을 지원하는 인터페이스로 휴대전화의 **진동 기능**으로 사용
- 닌텐도 Wii나 Xbox 등 콘솔게임기에서 실감나는 영상을 지원하기 위해 사용

### 5.5. 미래형 입출력장치
- **웨어러블 컴퓨터**(Wearable Computer): 컴퓨터 시스템을 몸에 부착하고 다니도록 설계
- 이동 중에도 데이터 입출력이 가능해야 하므로 특수한 형태의 장치가 필요하다.
	- 입력: **트위들러**(Twiddler), 장갑 형태의 입력장치
	- 출력: **HMD**(Head Mount Display)

## 6. 컴퓨터의 버스

### 6.1. 버스의 정의와 분류
- **버스**(Bus): 컴퓨터 내부 또는 외부의 부품들과 연결을 위해 사용되는 **주요 전기적 신호선들의 묶음**

- **용도별 구분**
	- **내부 버스**(Internal Bus)
		- 빠른 데이터 교환을 위해 **병렬통신** 방식을 사용하며 주소선, 데이터선, 제어선의 묶음으로 구성
		- **CPU 내부버스**: CPU 내부의 각 소자 간의 연결
		- **시스템 버스**: CPU와 기억장치 등의 연결
	- **외부 버스**(External Bus)
		- 컴퓨터 외부의 장치들과 통신을 위한 버스로 주로 **직렬통신** 방식으로 정보를 교환
		- SATA, USB, IEEE1394 등

### 6.2. 직렬 통신 vs 병렬 통신

| | **직렬 전송** | **병렬 전송** |
|---|---|---|
| **설명** | 동일한 전송선을 통해 **한 비트씩 순차적으로** 전송 | 송신할 비트에 대응되는 전송선이 각각 있어 **비트 블록을 한 번에** 전송 |
| **신호선** | 1개 + GND 또는 2개, 4개의 차동신호 | 데이터 수 + GND (보통 9~129개) |
| **장점** | 에러가 적고 **원거리 전송에 적합**, 라인 드라이버에 따라 **노이즈에 강한** 구조 가능 | 단위 시간에 **다량의 데이터를 빠른 속도**로 전송 |
| **단점** | 최대 통신거리 2~4Km (더 늘리려면 **리피터** 설치 필요) | 먼 거리를 보낼 수 없고, **노이즈에 약함** |
| **용도** | COM Port, SATA, USB, IEEE1394, PCIe, 장거리·광통신, LAN, 무선·위성통신 | Memory, Graphic Card 등 **단거리 통신**(PC의 시스템 버스) |

- 신호선 수가 적고 반도체 기술의 발달(에러 처리 및 **차동신호**의 사용)로 근래의 컴퓨터 외부 통신방식은 대부분 **직렬통신**을 사용한다.
	- HDD/ODD: 병렬(E-IDE) → 직렬(**SATA**)
	- 프린터: 병렬(센트로닉스 방식) → 직렬(**USB**)

### 6.3. 주요 병렬 통신방식 버스
- **시스템 버스**: CPU와 Memory 및 주변장치의 고속 데이터 통신
- **IEEE-488 Port**: 단거리 디지털 통신 버스로 주로 **계측기**에 사용, **GPIB**(General Purpose Interface Bus)라고도 함
- **프린터(센트로닉스) Port**: 초창기 컴퓨터 인터페이스, USB로 대체되어 거의 사용 안 함
- 기타: ATA, IDE, SCSI 등 → SATA, USB로 대체

### 6.4. 주요 직렬 통신방식 버스

#### USB (Universal Serial Bus)
- 컴퓨터 등의 정보기기에 주변 장치를 연결하기 위한 직렬 버스 규격
- RS-232C, IEEE 1284 병렬 포트, PS/2 커넥터를 교체하기 위해 개발되었으며, 1994년 컴팩, DEC, IBM, 인텔, NEC, 노텔 등 **7개사가 공동 개발**
- **주요 특징**
	- **Plug & Play**: 꽂으면 곧장 주변기기의 연결을 감지
	- **핫 스와핑**(Hot swapping): 전원이 켜진 상태에서도 장치를 연결하거나 분리 가능
	- ==USB 버전이 달라도 **하위 호환** 가능==

| 버전 | 전송 속도 |
|---|---|
| USB 1.0 / 1.1 | 최저 1.5Mbps ~ 최대 12Mbps |
| USB 2.0 | 480Mbps 추가 |
| USB 3.0 | 최대 **5Gbps**, **파란색** 커넥터·케이블 |
| USB 3.1 | 최대 **10Gbps**, **Type-C**는 상하방향이 없음 |

#### SATA (Serial AT Attachment)
- HDD 및 ODD용 인터페이스인 **병렬 ATA**(PATA, 통칭 'IDE', 최대 133MB/s)의 개선을 위한 직렬 인터페이스
- **종류**
	1. **SATA 3.0**: PCB 내장형 표준방식, 최대 **6Gbps**
	2. **eSATA**(External SATA): 외장하드를 위한 별도 규격
	3. **mSATA**(미니 SATA): 노트북·태블릿용 카드식 규격 → PCIe 기반 **M.2**로 대체 예상
	4. **SATA 익스프레스**: 최대 10Gbps → PCIe 기반 **U.2**로 대체 예상

#### PCIe (PCI-express)
- PC 메인보드에서의 **확장카드**를 위한 직렬 버스 표준 (그래픽카드, 사운드카드, TV 카드 등)
- 버전이 높을수록 전송속도가 빠르다.
- 슬롯은 1x, 4x, 8x, 16x 등 핀 개수에 따라 구분되며, ==핀 수가 적은 카드도 16x 슬롯에 문제없이 장착 가능==

| 버전 | 발표 | ×1 | ×16 |
|---|---|---|---|
| 1.0 | 2003 | 250 MB/s | 4.0 GB/s |
| 2.0 | 2007 | 500 MB/s | 8.0 GB/s |
| 3.0 | 2010 | 984.6 MB/s | 15.8 GB/s |
| 4.0 | 2017 | 1969 MB/s | 31.5 GB/s |

- **PCIe 응용 표준**
	- **M.2**(엠닷투) — '차세대 폼팩터'(NGFF)
		- mSATA는 물론 다양한 초소형 확장카드 사용이 가능
		- PCIe 미니 카드의 물리적 레이아웃과 커넥터를 사용
		- 지원 버스: PCIe 3.0, SATA 3.0, USB 3.0 → ==인터페이스 종류가 다르면 장착되지 않는다==
	- **U.2**(유닷투) — SFF-8639 인터페이스
		- PCIe를 이용한 SSD용 신규격 인터페이스, 기존 SATA-3 디바이스 사용 가능

#### 기타
- **IEEE-1394**(Fire Wire): 주로 PC와 AV 기기의 접속을 위해 만든 규격, 근래에는 많이 사용되지 않음
- **IrDA**(Infrared Data Association): 적외선 데이터 통신 규격, 초기에는 노트북에서 많이 사용했고 근래에는 임베디드 시스템이나 **리모컨**에서 주로 사용
