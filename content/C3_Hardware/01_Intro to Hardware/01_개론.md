## 1. 디지털 시스템
(Digital System)

### 1.1. 아날로그 vs 디지털
- **아날로그 신호**(Analog Signal)
	- 자연계에서 일어나는 물리적인 양은 시간에 따라 **연속적으로**(continuous) 변화한다.
	- 온도, 습도, 소리, 빛 등이 이에 해당한다.

- **디지털 신호**(Digital Signal)
	- 분명히 구별되는 **두 레벨의 신호값**만을 갖는다.
	- 1/0, High/Low, On/Off

- **시스템의 정의**
	- **디지털 시스템**: 이산(discrete)적인 정보를 가공·처리하여 최종 목적으로 하는 정보를 출력하는 모든 형태의 장치
	- **아날로그 시스템**: 연속(continuous)적인 정보를 입력받아 처리하고 연속적인 형태의 정보를 출력하는 시스템

### 1.2. 디지털 신호의 전압 레벨
- 디지털 정보를 표현하기 위해 **2진수 체계**(binary system)를 사용한다.
- 0 = Low = Off, 1 = High = On
- ==입력과 출력의 0, 1 전압 범위 조건이 서로 다르다.==
	- 출력: High $\geq 2.7V$, Low $\leq 0.4V$
	- 입력: High $\geq 2.0V$, Low $\leq 0.8V$
	- 출력 쪽 여유가 더 크므로 그 차이만큼이 잡음 여유(noise margin)가 된다.

### 1.3. 아날로그 ↔ 디지털 변환
- 아날로그 신호를 입력받을 때는 **ADC**(Analog-to-Digital Converter)가 필요하다.
- 처리된 출력을 아날로그로 내보낼 때는 **DAC**(Digital-to-Analog Converter)가 필요하다.
- **변환 과정**
	1. **표본화**(Sampling): 일정 시간 간격($T$)마다 신호의 값을 취한다.
	2. **양자화**(Quantization): 취한 진폭의 크기를 정해진 단계의 수치로 디지털화한다.
	3. **부호화**(Encoding): 양자화된 값을 2진 디지털 부호로 변환한다.
- 예: CD 오디오 시스템의 신호처리 과정 (녹음 시 ADC, 재생 시 DAC)

### 1.4. 디지털 시스템의 장점
1. **잡음에 강하고 신뢰도가 높다**
	- 2진수를 사용하므로 신호의 불안정 및 외부 잡음에 의한 영향이 적다.
	- 정보 처리의 정확성과 정밀도를 높일 수 있다.
2. **시스템 설계가 용이하다**
	- 전압 범위로 신호 값의 구분이 가능하므로 연산 기능만 구현하면 된다.
	- 이산적인 특징(0, 1) 때문에 정보를 저장하거나 가공하기 쉽다.
3. **유연성**: 프로그래밍으로 전체 시스템을 제어할 수 있어 규격이나 사양 변경에 쉽게 대응할 수 있다.
4. **경제성**: 반도체 기술 향상으로 크기가 줄고 대량 생산이 가능해져 가격이 인하된다.

> 이러한 장점 때문에 기존 아날로그 시스템이나 새로운 시스템의 대부분은 디지털 시스템으로 구성된다.

## 2. 컴퓨터 아키텍처
(Computer Architecture = 구조)

### 2.1. 하드웨어와 소프트웨어
- **하드웨어**(Hardware)
	- 각종 정보를 입력하여 처리하고 저장하는 동작이 실제로 일어나게 해 주는 **물리적인 실체**
- **소프트웨어**(Software)
	- 정보 처리의 종류를 지정하고 정보의 이동 방향·시간을 지정해 주는 **명령(command)들의 집합**(프로그램)

- **컴퓨터 아키텍처**: 하드웨어와 소프트웨어를 포함하는 컴퓨터 시스템 전체의 설계 방식
	- 계층 구조 (위 → 아래)
		1. 응용 소프트웨어
		2. 시스템 소프트웨어 (＋ Firmware)
		3. **ISA**(Instruction Set Architecture, 명령어 집합) ← 하드웨어와 소프트웨어의 인터페이스
		4. 입출력 장치 / CPU / 기억 장치
		5. 논리 설계 (Logic Design)
		6. 전자 회로 (Circuit Design)
	- *컴퓨터 구조 ≒ 스마트폰 구조 ≒ 제어시스템 구조*

### 2.2. 컴퓨터의 기본 구조와 기능
- **기본 구조 (4대 요소)**
	1. **중앙처리장치**(CPU: Central Processing Unit)
		- '프로세서', '처리기'라고도 하며, 컴퓨터 시스템 전체를 제어한다.
		- 모든 컴퓨터의 작동이 CPU(두뇌)의 제어를 받는다.
	2. **입력장치**: 키보드, 마우스, 스캐너, 디지타이저, 터치스크린, 조이스틱, CCD 등
	3. **출력장치**: 모니터(LCD, OLED), 프린터, 스피커, 플로터, 햅틱, HMD, HUD 등
	4. **기억장치**
		- 주기억장치: RAM, ROM
		- 보조기억장치: HDD, SSD, USB 메모리 등

- **컴퓨터의 4대 기능**
	1. 데이터 처리 (Data Processing)
	2. 데이터 저장 (Data Storage)
	3. 데이터 이동 (Data Movement)
	4. 제어 (Control)

- **소프트웨어의 분류**
	- **응용 소프트웨어**: 최종 사용자를 위해 개발된 S/W, 주로 High-level 언어로 작성
	- **시스템 소프트웨어**: 컴퓨터를 사용하기 위한 가장 기본적인 S/W
		- 운영체제 (프로세스·메모리·주변장치·파일 관리)
		- 컴파일러, 어셈블러, 에디터, 디바이스 드라이버
		- **펌웨어**(Firmware): ==BIOS = POST + 초기화 + 부트로더==

### 2.3. 명령어의 종류
- **매크로 명령어**(Macro Instruction)
	- 우리가 일반적으로 말하는 명령어 = 기계어(≒니모닉)
- **마이크로 명령어**(Micro Instruction) → CISC의 경우
	- 매크로 명령어를 처리하기 위한 **CPU 내부**의 세부 명령어
	- CPU 내부 ROM에 저장되어 프로그래머에게는 보이지 않는다.
	- 마이크로 프로그램 = 마이크로 명령어들의 집합
	- 예: `ADD addr` → `MAR ← MBR(addr)`, `MBR ← M`, `AC ← AC + MBR`

- **언어 계층**: High-level Language → Assembly Language → Machine Language(이진수)

### 2.4. 프로세서 분류
> 명령어 개수에 따른 중앙처리장치의 분류

- **CISC**(Complex Instruction Set Computer)
	- 복합적인 연산들을 처리하는 다양한 종류의 명령어를 가진 기존의 프로세서
	- 상대적으로 **적은 레지스터** 묶음
	- 수백 가지의 명령어 → CPU 내부에서 **마이크로프로그램 방식**으로 제어장치를 구성
	- 예: 인텔 x86, 모토롤라 68xxx

- **RISC**(Reduced Instruction Set Computer)
	- CISC의 한계를 극복(명령어 수를 줄임)하고자 제안된 구조 → 빠른 속도
	- **많은 레지스터**가 내부에 있어 주 메모리 참조 횟수가 감소한다.
	- 뛰어난 계산 능력, 낮은 전력 소모로 **임베디드 분야**에 활용된다.
	- CPU 내부에서 **고정배선 제어장치**를 구성한다.
	- 예: PowerPC, MIPS, SPARC, ARM, AVR, PIC

- **제어장치(Control Unit) 설계 방식 비교**

| 구분 | 마이크로 프로그램 제어방식 (CISC) | 고정배선 제어방식 (RISC) |
|---|---|---|
| 과정 | 기계어 → 마이크로 프로그램 변환 → 마이크로 명령어 읽기 → 제어용 논리회로 구동 | 기계어 → (논리회로를 구동하는 제어신호) → 제어용 논리회로 구동 |
| 속도 | 상대적으로 느림 | 빠름 |
| 유연성 | 높음 (명령어 추가·수정 용이) | 낮음 |

### 2.5. 멀티코어와 IC
- **멀티코어 기술**
	- 동일한 반도체 **die**(다이, chip)에 두 개 이상의 코어를 집적시켜 CPU 성능을 향상시킨다.
	- *원래 die와 chip은 같은 의미이나, 완성된 IC 부품을 chip이라 부르기도 한다.*
	- 예: Intel i7 (Quad Core), AMD Athlon64, 삼성전자 엑시노스 (Octa Core)
- **IC**(Integrated Circuit)
	- 디지털 및 아날로그 회로를 하나의 부품 내에 제조한 것
	- 반도체 기술을 활용하며, 집약도가 높아져 단위 면적당 많은 회로를 내장한다.

### 2.6. 메모리 계층 구조
- 성능이 좋은 메모리는 비싸기 때문에 많은 양을 사용하지 못한다.
- 대신 저가의 느린 메모리를 많이 사용하고, 필요한 내용을 빠른 메모리로 복사해 속도를 향상시킨다.
- **계층 (빠름·소용량·고가 → 느림·대용량·저가)**
	1. **CPU 레지스터**: 속도가 가장 빠른 기억장치 (F/F 사용)
	2. **캐시(Cache) 메모리**: 속도가 빠름, 주로 SRAM 사용
	3. **주기억장치**: 일반적으로 DRAM
	4. **보조기억장치(2차 저장장치)**: HDD, SSD 등
	5. **보조기억장치(3차 저장장치)**: 자기 테이프, CD-ROM, DVD-ROM
- 레지스터 ~ 주기억장치까지는 CPU가 **직접 참조**, 2·3차 저장장치는 **간접 참조**한다.

### 2.7. 기억장치
- **주기억장치**
	- CPU가 프로그램 수행 시 직접 접근하여 데이터를 읽거나 쓰는 메모리
	- CPU가 수행할 명령어와 데이터를 저장한다.

| 종류 | 특징 | 휘발성 |
|---|---|---|
| **DRAM** (Dynamic RAM) | 전원이 공급되는 중에도 **주기적인 재충전(refresh)**이 필요. 일반적으로 RAM이라 부름 | 휘발성 |
| **SRAM** (Static RAM) | 전원이 공급되는 동안 데이터 유지. DRAM보다 접근속도가 빠르나 **가격이 비쌈** → 캐시메모리로 사용 | 휘발성 |
| **ROM** (Read Only Memory) | 읽기전용, 펌웨어(부팅에 필요한 명령어)를 기록 | **비휘발성** |

- **캐시메모리**(Cache Memory)
	- 자주 사용되는 데이터를 복사해 두는 장소로, CPU가 제일 먼저 접근하는 빠른 메모리
	- 캐시에서 찾지 못하면 DRAM → 보조기억장치 순으로 접근한다.
	- 근래에는 CPU 내부에도 다단계 캐시 시스템을 구성한다. (예: Intel i7의 3단계 내부 캐시)

- **보조기억장치**
	- 주기억장치 이외의 대용량 저장을 위한 메모리 시스템
	- I/O Bus(시스템 버스)를 통해 SATA, USB 등 표준화된 방식으로 CPU와 연결된다.
	- 종류: HDD, SSD, 이동식 하드디스크, 광디스크(CD/DVD/Blu-ray), USB 메모리, 메모리 카드

- **반도체 메모리 분류**
	- **RAM**(휘발성)
		- DRAM → SDRAM, RDRAM, DDR SDRAM
		- SRAM
	- **ROM**(비휘발성)
		- EPROM, EEPROM, FLASH → NOR, NAND

### 2.8. 버스
- **버스**(Bus): 동일한 기능을 갖는 전기 신호선들의 묶음
- **CPU 내부 버스**: CPU 내부의 각 기능성 모듈들을 연결하는 버스
- **시스템 버스**(= I/O 버스): CPU와 외부의 주변장치(Peripheral)를 연결하는 버스
	- ==시스템 버스 ≠ 내부 버스==

- **시스템 버스의 구성**
	1. **주소 버스**(Address Bus): CPU가 접근할 기억장치·입출력장치의 **주소**를 전달하는 통로
	2. **데이터 버스**(Data Bus): CPU와 기타 장치 사이에서 **데이터**를 전달하는 통로
	3. **제어 버스**(Control Bus): CPU가 다양한 종류의 **제어 신호**를 전달하는 통로

## 3. 임베디드 시스템
(Embedded System)

### 3.1. MPU vs MCU
- ==**MPU**(Micro-Processor Unit) = 마이크로프로세서 = CPU==
	- 하나 또는 복수개(멀티코어)의 CPU 기능을 하나의 실리콘 칩에 집적한 처리장치
	- 예: 인텔 x86 계열, PowerPC(모토롤라+IBM) 계열, SPARC 계열

- ==**MCU**(Micro-Controller Unit) = 마이크로컨트롤러 = CPU + 주변장치==
	- **단일 칩 마이크로컴퓨터**(One-Chip / Single-Chip Microcomputer)라고도 부른다.
	- 한 개의 칩 내부에 CPU, ROM, RAM, 입출력 제어 인터페이스 회로 등을 내장한다.
	- 범용 목적보다는 **기기 제어용**으로 주로 사용된다.
	- 예: 인텔 8051, 마이크로칩 PIC 시리즈, Atmel AVR 시리즈, ARM 시리즈

- **참고**
	- **SoC**(System on Chip): 다양한 기능을 하나의 칩에 만드는 기술
	- **AP**(Application Processor): 특수한 전용 용도로 개발된 SoC
		- 퀄컴 Snapdragon, 엔비디아 Tegra, 인텔 Atom, 프리스케일 i.MX, 삼성전자 Exynos, 애플 A-series

### 3.2. 정의 및 특징
- **정의**: 마이크로프로세서 혹은 마이크로컨트롤러를 **내장**(embedded)하여 원래 제작자가 지정한 기능만을 수행하는 장치
	- 근래에는 주로 MCU가 사용된다.
	- 보다 큰 시스템의 일부로서 특별한 업무를 수행하기 위한 H/W와 S/W를 포함하는 특정 응용 시스템

- *임베디드 시스템의 특징*
	1. 수행하는 기능이 **미리 정해진다**.
	2. 소형, 경량, 저전력
	3. 가격에 민감하다.
	4. 안정성, 신뢰성이 뛰어나야 한다. (고신뢰성)
	5. **Real-time** 기능을 필요로 하는 시스템이 많다.
	6. 제한된 시스템 자원
	7. 호환성
	8. 깔끔한 오류 처리
	- 키워드: 경량화·최적화, 저전력화, 고신뢰성, 네트워크 지원, 멀티미디어 지원

### 3.3. 구성
- **하드웨어**: 프로세서, 메모리 장치(ROM, RAM), 입출력 장치(네트워크 장치, **센서**, **구동기(Actuator)**)
	- 마이크로프로세서보다는 주로 **마이크로컨트롤러**를 사용한다.
- **소프트웨어**: 임베디드 운영체제(OS), 시스템 S/W, 응용 S/W
- 범용이 아닌, 요구되는 성능을 만족시키기 위한 **특수 목적의 저가 시스템**(H/W + S/W)이다.

### 3.4. 활용 분야
> From Small Devices To Factory Automation and Safety-Critical System

- **정보가전**: 세탁기, 오디오, 인터넷 냉장고, HDTV, 전자레인지, DVR
- **제어분야**: 공장자동화(FA), 가정자동화(HA), 로봇 제어, 공정제어
- **정보기기**: 핸드폰, PDA, 스마트폰, LBS
- **네트워크기기**: 교환기, 라우터, 공유기, 홈 게이트웨이, 셋톱박스
- **게임기기**: 가정용 게임기(PS2, Xbox, Wii), 지능형 장난감
- **항공/군용**: 비행기(보잉 747-400, A380), 우주선·우주왕복선, 로켓, 야전 이동단말(GPS, GIS)
	- NASA Pathfinder: 실시간 운영체제 **VxWorks** 탑재로 유명한 대표적 실시간 시스템
	- 항공기·우주왕복선은 보통 수백 개의 프로세서를 탑재한다.
	- 국방: 패트리어트 미사일 / 조선: 이지스함
- **물류/금융**: ATM, RFID, POS 단말기, 물류·영업단말
- **차량/교통**: 자동차(ECU), ITS(지능형 교통시스템), 조선
	- 근래에는 차량 내에 수십~100여 개의 MCU가 사용되며 다양한 네트워크로 연결된다. (복잡한 분산 컴퓨터)
- **사무/의료**: 전화기, 프린터, 스캐너, 복합기, Heart pacer, 수술로봇, 증강현실장비

- **가정자동화(HA)**: 집안의 모든 것을 리모컨 혹은 원격으로 제어하는 것이 목표이며, 현재는 웹 패드·음성인식을 이용한 제어로 발전 중이다.
- **공장자동화(FA)**: 센서와 제어 시스템, 로봇 등으로 무인시스템을 구축한다. 생산성 증대(인건비 감소, 오류 감소, 품질 균일화, 생산기간 단축) 효과가 있으며, 실시간·임베디드 시스템 발전의 원동력이 되었다.

### 3.5. 미래 전망
컴퓨팅 패러다임의 변화
- ~1980: 1대 컴퓨터 : 다수 (메인프레임, Server-to-Client)
- ~2000: 1대 컴퓨터 : 1인 (PC, 노트북)
- ~2010: 다수 컴퓨터 : 1인 (휴대전화, PDA, 정보가전 — Ubiquitous Networking)
- ~2020: 사람 + 컴퓨터 + 사물 (Things to Things — [[IoT]], Smart Home, Wearable Computers)

유비쿼터스(Ubiquitous) 컴퓨팅과 [[IoT]]의 발달로 사람, 컴퓨터, 사물이 모두 네트워크로 연결되는 방향으로 발전하고 있다.
