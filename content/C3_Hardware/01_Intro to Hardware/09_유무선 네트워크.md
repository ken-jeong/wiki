## 1. 통신과 네트워크

- **통신**(Communication): 컴퓨터와 단말 장치 사이, 컴퓨터와 인간 사이, 인간과 인간 사이에 정보·데이터·메시지 등을 전달하는 것의 총칭
- **컴퓨터 통신**: 통신 회선에 연결된 하나 또는 그 이상의 컴퓨터나 단말기를 이용한 정보의 전달
- **통신망**: 통신 시스템들을 통신 회선으로 연결하여 통신이 가능하도록 한 시스템
- **네트워크**(Network): 'net(그물)'와 'work(일하다)'의 합성어로, 컴퓨터끼리 정보를 주고받을 수 있도록 연결한 통신망
	- 통신용 매체를 공유하는 여러 시스템이 **프로토콜**을 사용하여 데이터를 주고받을 때 이들을 하나의 단위로 통칭
	- ==**통신 ≫ 네트워크**==

- **컴퓨터 통신의 기본 구성 4가지**
	1. **송신기 / 수신기**
	2. **전송매체**(Media): 유선, 무선
	3. **데이터**(Data): 문서, 사진, 음성, 영상, 센서
	4. **프로토콜**(Protocol, 전송규약): 데이터를 주고받을 때 수행되는 절차
		- 서로 다른 기종의 컴퓨터끼리 통신하기 위해 미리 정해 놓은 규칙 (예: RS-232c, TCP/IP)

## 2. 통신 방식의 분류

### 2.1. 데이터의 종류에 따른 분류
- **아날로그 통신**
	- 아날로그 데이터는 시간에 따라 크기가 **연속적으로 변하는** 정보 (소리, 압력, 온도)
	- 전송거리가 멀어짐에 따라 **감쇄현상**이 발생 → 일정 거리마다 **증폭기** 사용
- **디지털 통신**
	- 디지털 데이터는 **불연속적인 값**을 가지며 임의의 값의 정수 배를 다루는 데이터 (0과 1)
	- 거리의 제한을 해결하기 위해 **리피터** 사용

### 2.2. 데이터 비트의 처리 방법에 따른 분류
- **직렬전송**: 한 비트씩 전송해 속도는 느리지만 **통신회선 비용이 아주 저렴**
	- 주로 **원거리** 전송에 사용 (RS-232C, RS-423)
- **병렬전송**: 전송 속도는 빠르나 통신회선 구축에 **많은 비용**
	- 단말장치 간 연결에는 거의 사용하지 않고, **거리가 짧은 CPU와 메모리 간**의 연결에 많이 사용

### 2.3. 데이터 흐름의 방향성에 따른 분류

| 방식 | 설명 | 예 |
|---|---|---|
| **단방향**(simplex) | 한 방향으로만 전송 가능 (한 쪽은 송신만, 다른 쪽은 수신만) | 방송국 ↔ 라디오·TV |
| **반이중**(half duplex) | 양방향 통신 가능하나 **동시 전송은 불가능** (한 시점에 한 방향) | 무전기 |
| **전이중**(full duplex) | 두 단말이 **동시에 양방향**으로 데이터 전송 (송신 시작 전 가능여부 확인 필요) | 일반 데이터 통신, 전화기 |

### 2.4. 통신 시의 기준(클럭) 여부에 따른 분류
- **비동기 전송**(asynchronous)
	- 송수신장치가 서로 **독립적인 시스템 클럭**을 사용하지만 **기준 클럭이 없다.**
	- **시작 비트와 정지 비트**로 동기를 맞추고 데이터를 인식
	- 구조가 간단하므로 **전송 비용이 저렴**
- **동기 전송**(synchronous)
	- 전송 효율을 높이기 위해 서로 약속된 일정한 데이터 형식에 따라 **기준 클럭에 맞추어** 전송
	- 전송 도중 오류가 발생하면 동일한 데이터를 **재전송**하여 오류를 복구

### 2.5. 전송 매체에 따른 분류
- **전송매체**: 송신측과 수신측 사이를 상호 연결하는 **물리적 선로**
	- ==네트워크는 접속 형태와 관계없이 **반드시 전송매체가 필요**하다.==

1. **유선 통신**
	- 물리적인 선을 이용하여 통신망을 구성
	- 속도가 빠르고 **보안 측면에서 안전**하나 **설치 비용이 비쌈**
2. **무선 통신**
	- 전파를 이용하여 **고정식** 무선 통신망을 구성
	- 설치가 쉽고 저렴하나 유선에 비해 **보안이 취약**
3. **모바일 통신**
	- 무선 통신에서 새롭게 세분된 분야 → **이동 중 사용** 강조
	- 수 킬로미터 지역을 **셀(Cell) 형태**로 망을 구성해 이동 중에도 사용 가능 → 이동 통신

*참고. ITU의 5G 정의*
- 다운로드 속도 20Gbps, 최저 다운로드 속도 100Mbps, 1㎢ 반경 안의 **100만개 기기**에 IoT 서비스 제공, 시속 500㎞ 고속열차에서도 자유로운 통신 가능

### 2.6. 유선통신 매체
1. **일반 전선**: 가장 일반적으로 많이 사용
2. **꼬임선**(twisted pair cable): 절연체로 덮인 두 가닥의 전선을 **나선형으로 꼬아서** 만든 전송매체
	- ==두 신호선을 **차동신호**로 사용할 경우 외부 노이즈를 두 선이 함께 받아 안정된 신호 전송==
	- **구조에 따른 분류** (랜 케이블)
		- **UTP**(Unshielded): 신호선 2개씩을 나선형으로 꼬아 놓은 형태 — 사무실용 LAN, **자동차용 CAN** 케이블
		- **FTP**(Foil Screened): UTP의 선들을 **알루미늄 호일**로 감싸 차폐 — 절연 기능이 탁월해 **공장 배선용**
		- **STP**(Shielded): 2선씩 쌍으로 꼬아진 케이블마다 **쉴드**가 있음 (추가로 바깥에 은박이 하나 더 있으면 S/STP)
	- **통신속도에 따른 구분**: **Category(카테고리)** — 미국전자산업진흥회(EIA)에서 지정, ==숫자가 클수록 빠른 통신 지원==
3. **동축 케이블**(Coaxial cable)
	- 중앙의 전도체와, 이를 감싸는 절연체 밖에 또 하나의 전도체를 구성
	- 우수한 **주파수 특성**으로 높은 대역폭과 빠른 전송이 가능하나 **비쌈** → 유선 방송, CATV
4. **광섬유 케이블**(Optical Fiber cable)
	- 전기를 **빛**으로 바꾸어 전송하는 신호선
	- 일반적으로 유리섬유를 사용하나 최근에는 플라스틱 제품도 사용 (**POF**)
	- **10Gbps 이상**의 고속 전송이 가능
	- ==**전자기파의 간섭을 받지 않고** 대역폭도 아주 크며 보안성도 우수==

## 3. 네트워크 방식의 분류

### 3.1. 구성 형태(Topology)에 따른 분류
> 네트워크를 구성하는 컴퓨터 간의 연결 방법을 **네트워크 위상** 또는 **토폴로지**라고 부른다.

1. **버스(bus) 구조**
	- 구조가 간단하고 **케이블 비용이 최소**
	- ==이미 다른 노드가 전송 중이면 **충돌**이 발생 → **CSMA/CD, CSMA/CA** 등의 기법 필요==
		- 노드 수가 많거나 트래픽이 많아지면 충돌이 잦아져 성능이 저하
	- **자동차나 산업용 네트워크**에서 많이 사용
2. **스타(star) 구조**
	- 노드들이 **허브**에 점대점(point-to-point) 링크로 연결
	- ==**허브에 의해 성능 및 신뢰성이 결정**됨==
	- 중앙집중식이라 **고장 발견·유지보수가 쉽고** 전송제어가 간단
	- 기업, 학교, 가정에서 일반적으로 많이 사용 (유선 랜, Wi-Fi, Bluetooth)
3. **링(ring) 구조**
	- 한 노드에서 전송한 데이터는 원을 따라 **한 방향**으로 전송
	- 목적지가 아닌 노드에서는 매번 **신호를 재생**하여 다음 노드로 전송 → 전송 도중의 오류를 줄일 수 있음
	- 장애 발생 호스트를 쉽게 찾을 수 있고, **노드 수가 증가해도 성능에 큰 영향이 없음**
4. **메시(mesh) 구조**
	- 일부 회선에 장애가 발생해도 **다른 경로**를 통해 전송 가능 (중간의 노드가 **중계 기능**)
	- 복잡하고 많은 통신 회선이 필요해 비용이 높지만 **신뢰성이 중요한 네트워크**에서 사용
	- ==무선 네트워크에서 많이 사용 → **ZigBee**==

### 3.3. 규모에 따른 분류

| 구분 | 설명 |
|---|---|
| **WAN** (Wide Area Network) | 하나의 국가나 국가 간을 연결. 대표적인 것이 **인터넷**. 구축에 많은 비용 |
| **MAN** (Metropolitan Area Network) | LAN이 확장되어 **도시** 정도의 규모를 연결. **ISP** 통신사업자가 제공·관리 |
| **LAN** (Local Area Network) | 좁은 지역(하나의 조직이 관리하는 지역)의 네트워크 장비들을 연결 |
| **HAN** (Home Area Network) | 전선, 케이블, 또는 무선으로 **가정**의 디지털 장비들을 연결 |
| **PAN** (Personal Area Network) | 단거리 무선 기술로 **개인 휴대장비**를 연결 (블루투스, Wi-Fi, NFC, ZigBee, UWB) |

- **LAN의 종류**
	1. **이더넷**(ethernet): 1976년 **Xerox**사 개발, **10Mbps**, **CSMA/CD** 알고리즘
	2. **고속 이더넷**(fast ethernet): **100Mbps**, 100BASE-T
	3. **기가비트 이더넷**: **1Gbps**
	4. **FDDI**(Fiber Distributed Data Interface): **광섬유**를 사용한 고속 LAN, 많은 대역폭과 빠른 전송이 필요한 **백본망**에 많이 사용

### 3.4. 응용 분야에 따른 분류
- **인터넷**: 사용자의 제한 없이 사용하는 네트워크 통신망
- **사설망**: 기업이나 국가에서 **제한된 사용자만** 사용할 수 있게 구축한 통신망
- **자동차용 네트워크**: 자동차 내부의 제어장치 간 또는 외부 통신용
- **산업용 네트워크**: 각종 산업용 설비 간의 통신용
- **센서 네트워크**: 유비쿼터스 구현을 위해 센서들을 연결

## 4. 임베디드 시스템용 주요 무선 기술
> 근래에는 **IoT** 등의 확산으로 무선통신 기술이 매우 중요한 요소가 되고 있다.

### 4.1. 와이파이 (Wi-Fi)
- 유선랜을 무선으로 변경해 사용하는 **근거리 무선 기술 표준** → **무선랜**
- **2.4GHz / 5GHz** 주파수 사용
- ==가장 **빠른 무선통신 속도**를 지원하나 **1:1 통신방식**==
- 표준: **IEEE 802.11xx** (최근에는 **Wi-Fi 6**, 802.11ax가 널리 보급)

- *참고: **가정용 유무선 공유기**의 기능*
	1. ***라우터** 기능: WAN ↔ LAN*
	2. ***NAT** 기능(IP 공유기): 고정(공인) IP → 여러 개의 유동(가상) IP*
	3. ***허브** 기능: 4개/8개 유선포트*
	4. *유선: 100Mbps, 1Gbps*
	5. *무선(Wi-Fi): **AP**(Access Point) 기능, 802.11n(300Mbps), 802.11ac(Gbps)*
	6. *기타: 미디어 서버, NAS, WOL(Wake-Up LAN)*

### 4.2. 블루투스 (Bluetooth)
- 휴대폰, 노트북, 헤드폰 등의 휴대기기를 서로 연결해 정보를 교환하는 **근거리 무선 기술 표준**
- 표준: **IEEE 802.15.3**
- **10미터 안팎의 초단거리**에서 **저전력** 무선 연결이 필요할 때 사용
- **ISM 주파수 대역**인 2400~2483.5MHz(**2.4GHz**) 사용
	- ***ISM**(Industrial Scientific and Medical): 산업·과학·의료용으로 할당된 주파수 대역으로, **전파 사용 허가가 필요 없어** 저전력 개인 무선기기에 많이 쓰인다. (아마추어 무선, 무선랜, 블루투스)*
- **Master/Slave** 방식으로 일반적으로 **페어링(Pairing)** 기법을 사용 → **1:1**(point-to-point) 방식

### 4.3. NFC (Near Field Communication)
- 무선태그(**RFID**) 기술 중 하나로 **13.56MHz** 주파수를 사용하는 **비접촉식** 통신 기술
- ==**10cm 이내**의 아주 가까운 거리의 무선 통신 기술, 데이터 통신 속도 **424Kbps**==
- 통신거리가 짧아 상대적으로 **보안이 우수**하고 **가격이 저렴**하다.
	- 블루투스나 지그비 등 경쟁기술에 비해 **보안성과 편의성**이 좋다.
- **데이터 읽기와 쓰기 기능을 모두** 사용할 수 있다.
- 교통요금, 티켓요금, 상점 요금 지불, 여행 정보 전송, 출입통제 잠금 장치 등 **적용 범위가 광범위**하다.

### 4.4. 지그비 (ZigBee)
- 'Zigzag'와 벌을 뜻하는 'Bee'의 합성어 — 벌이 꽃을 쫓아 옮겨 다니듯 구석구석 움직이며 통신한다는 뜻
- **250Kbps 이하**의 저속 국제 표준인 **IEEE 802.15.4** 물리계층 기반의 무선 네트워킹 기술
- ==**저전력, 저비용, 저속**이 특징==
- 반경 **30m** 내에서 20~250kbps의 속도로 데이터를 전송
- 하나의 무선 네트워크에 최대 **255대**의 기기를 연결 가능
- **유비쿼터스 센서 네트워크(USN)**의 핵심 기술
- 다양한 토폴로지를 구성할 수 있으며, ==특히 **메시(mesh) 구조**가 가능하여 원거리 무선네트워크를 구축해도 중간에 **별도의 중계기가 불필요**하다.==
- 홈 오토메이션, 산업용기기 자동화, 물류 및 환경 모니터링 등에 활용되며 근래의 **IoT 분야**에서 많이 사용된다.

## 5. 주요 산업 분야별 네트워크

### 5.1. 자동차용 네트워크
- 최근의 자동차는 적게는 수십 개에서 많게는 **100여 개의 ECU**(Electronic Control Unit)를 사용하기 때문에, ECU 간 통신을 위해 다양한 차량 내부 네트워크가 **복합적으로** 사용된다.
- 초기에는 **배선을 줄이기 위한 목적**으로 ECU를 사용했으나, 근래에는 각종 부가기능 추가를 위해 새로운 ECU 및 센서, 액츄에이터가 추가로 도입되고 있다.

| 네트워크 | 특징 |
|---|---|
| **CAN** (Controller Area Network) | **2개의 차동 신호선**으로 버스 구성, 최대 **1Mbps**. 자동차용뿐 아니라 **산업용으로도 매우 많이 사용** |
| **LIN** (Local Interconnect Network) | MCU의 **UART** 기능을 이용한 **1선**의 저가형 네트워크 |
| **FlexRay** | 2선 또는 4선의 차동 신호선을 이용한 **10Mbps** 네트워크 |
| **MOST** | **플라스틱 광섬유**를 이용, 최대 **150Mbps**의 **멀티미디어** 정보 네트워크 |
| **CAN FD** (Flexible Data-rate) | CAN의 속도(**2.5Mbps**) 및 효율성을 높인 개량형 |
| **Automotive Ethernet** | 기존 이더넷을 차량용으로 변경한 차세대 네트워크, **2선으로 100Mbps** |

### 5.2. 산업용 네트워크 — Field bus (필드 버스)
1. **PROFIBUS**: 공장자동화·공정자동화 등 산업자동화 분야에서 활발히 사용, 최대 **12Mbps**, 최대 **126개** 어드레스
2. **CAN BUS**: 자동차용에서 산업용 필드버스로 확산, 최대 **1Mbps**
3. **CANopen / DeviceNet**: CAN 버스의 상위 개념, CANopen은 최대 **127개**, DeviceNet은 **64개** 노드 지원
4. **Modbus**: 사용이 단순하고 **로열티가 없는** 시리얼 버스, 최대 **247개** 노드, RS-232 및 RS-485 사용, 115bps
5. **CC-Link**: **RS-485** 기반, 최대 **64개** 노드, 최대 **10Mbps**
6. **Ethernet 기반 산업용 필드버스**: EtherCAT, EtherNet/IP, PROFINET, Ethernet POWERLINK, Sercos Ⅲ, CC-Link IE, Modbus/TCP
