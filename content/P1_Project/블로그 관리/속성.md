속성은 노트 맨 위의 `---` 사이에 적는 정보다.

## 기본 속성
| 속성        | 의미                        |
| --------- | ------------------------- |
| `aliases` | 다른 이름                     |
| `type`    | 노트 종류                     |
| `tags`    | 분류 키워드                    |
| `draft`   | `true`: 정리 중, `false`: 완료 |
| `date`    | 기준 날짜 (`YYYY-MM-DD`)      |

## 노트 종류 (`type`)
- `Lecture`: 강의·학습
- `Seminar`: 세미나
- `Research`
- `Archive`
- `PARA`: 프로젝트·관리 영역·참고·보관 자료
- `Ontology`: 개념과 관계
- `Index`: 목차
- `Board`: 칸반 보드

## 개념 관계 (`Ontology`)
- `up` / `down`: 상위 / 하위 개념
- `same`: 같은 수준의 관련 개념
- `prev` / `next`: 먼저 / 다음에 읽을 개념

## 기타
- `kanban-plugin`: 칸반 설정 (`board`)
- `cssclasses`: CSS 클래스 목록
