속성은 노트 맨 위의 `---` 사이에 적는 정보다.

## 기본 속성
| 속성        | 의미                        |
| --------- | ------------------------- |
| `aliases` | 다른 이름                     |
| `type`    | 노트 종류                     |
| `tags`    | 분류 키워드                    |
| `draft`   | `true`: 정리 중, `false`: 완료 |
| `date`    | 기준 날짜 (`YYYY-MM-DD`)      |

## 노트 종류 (`type`)
- `Lecture`: 강의·학습
- `Seminar`: 세미나
- `PARA`: 프로젝트·관리 영역·참고·보관 자료
- `Ontology`: 개념과 관계
- `Index`: 목차
- `Board`: 칸반 보드

## 읽기 흐름 (일반 노트·`Ontology`)
- `prev` / `next`: 먼저 / 다음에 읽을 노트
- 연결할 노트가 있을 때 내부 링크 목록으로 작성하고, 없으면 비워 둔다.

## 개념 관계 (`Ontology`)
- `up` / `down`: 상위 / 하위 개념
- `same`: 같은 수준의 관련 개념

## 기타
- `kanban-plugin`: 칸반 설정 (`board`)
