## 1. 네트워크 개요
### 1.1. 컴퓨터 네트워크의 정의
**컴퓨터 네트워크**
- 전송매체에 의해 연결된 컴퓨터들이 상호 간에 정보를 교환하는 시스템

**구성 요소**
- 송신자, 수신자, 전송매체(케이블, 무선)

**프로토콜**
- 통신을 위한 규약(약속)

### 1.2. 네트워크의 역사
- **Ethernet**(1974): 제록스 사 개발
- **WWW**(1992): 인터넷의 급격한 확산을 가져옴

### 1.3. OSI 7계층
**OSI 7계층**
- 네트워크 통신이 일어나는 과정을 7단계로 정의한 **표준 네트워크 통신 모델**이다.
- 이 모델은 복잡한 통신 과정을 단계별로 나누어 관리함으로써, **데이터 흐름을 한눈에 파악**하기 쉽고, **문제 발생 시 어느 계층의 문제인지 파악**(트러블슈팅)하기 용이하게 만들어준다.

[[OSI 7계층 모델]]
- 각 계층은 상위 계층의 요청을 받아 자신의 역할을 수행하고, 하위 계층으로 데이터를 넘긴다.
- (반대로 데이터를 받을 때는 하위에서 상위로 올라간다.)

| 계층     | 주요 역할                            | 대표 프로토콜/장비           |
| :----- | :------------------------------- | :------------------- |
| 응용     | 사용자 인터페이스 제공                     | HTTP, FTP, DNS, SMTP |
| 표현     | 데이터 인코딩, 암호화, 압축                 | JPEG, MPEG, SSL/TLS  |
| 세션     | 통신 세션 설정, 유지, 종료                 | SSH, NetBIOS         |
| 전송     | 데이터 전송 단위(Segment), 흐름 제어, 오류 제어 | TCP, UDP             |
| 네트워크   | 경로 결정(Routing), 주소 지정(IP)        | IP, ICMP, 라우터        |
| 데이터 링크 | 물리적 링크를 통한 데이터 전송(Frame), MAC 주소 | 이더넷, 스위치, 브릿지        |
| 물리     | 비트 단위 데이터 전송, 전기적/기계적 신호         | 케이블, 허브, 리피터         |

#### 상위 계층
**응용 계층**
- 사용자와 가장 가까운 계층으로, 사용자가 직접 사용하는 서비스(브라우저, 이메일 등)가 동작한다.

**표현 계층**
- 데이터의 형식을 정의한다. (데이터 암호화, 압축, 인코딩/디코딩)
- 데이터의 형식이 달라도 서로 이해할 수 있도록 변환해 주는 계층이다.

**세션 계층**
- 응용 프로세스 간의 통신을 관리한다.
- 연결을 만들고, 유지하고, 종료하는 과정을 제어한다. (동기화 지점 설정 등)

#### 하위 계층
**네트워크 계층**
- 데이터를 가장 효율적인 ==경로를 찾아 전달하는 라우팅(Routing)==을 수행한다.
- ==IP 주소==를 사용하여 출발지와 목적지를 식별한다.

**데이터 링크 계층**
- 물리 계층을 통해 데이터가 안전하게 전달되도록 한다.
- ==MAC 주소==를 사용하여 물리적인 장치 간의 통신을 담당한다. (같은 LAN)

**물리 계층**
- 데이터를 전기적인 신호(0과 1)로 바꾸어 전송한다.
- 하드웨어적인 특성을 다룬다. (케이블, 커넥터, 전압 등)

## 2. 네트워크 장치와 교환 방식
### 2.1. 전송매체
**대역폭**
- 전송 가능한 주파수 범위(데이터 전송량과 비례)

**종류**
- **꼬임 쌍동선**: UTP/STP (구리선)
- **동축 케이블**: 높은 대역폭, 유선 방송 등에 사용
- **광섬유**: 빛을 이용, 초고속, 보안성 우수
- **위성**: 지상국 사이의 중계소 역할

### 2.2. 네트워크 접속장치
**리피터**(Repeater)
- 신호 증폭(거리 연장)

**모뎀**(Modem)
- 디지털 ↔ 아날로그 신호 변환

**NIC**(랜카드)
- 디지털 신호 직접 전송

**허브**(Hub)
- 여러 장치 연결
- 더미 허브(단순 전달) vs 스위칭 허브(목적지로만 전달, 효율 높음)

**브리지**(Bridge)
- 같은 LAN 연결, 트래픽 감소

**라우터**(Router)
- 서로 다른 네트워크 연결, 최적 경로 설정(IP 주소 기반)

**게이트웨이**(Gateway)
- 서로 다른 프로토콜 변환 및 연결

## 3. 네트워크의 분류
**LAN**(Local Area Network)
- 근거리 통신망(집, 사무실, 캠퍼스)
- **특징**: 고속, 낮은 오류율, 이더넷(Ethernet)이 표준

**MAN**(Metropolitan Area Network)
- 도시 규모의 통신망
- LAN과 WAN의 중간

**WAN**(Wide Area Network)
- 광역 통신망(국가, 대륙 간 연결)
- **특징**: 인터넷이 대표적, 구축 비용 높음, LAN보다 속도가 느림

## 4. 네트워크의 활용 및 이해
### 4.1. 네트워크 설정 및 확인
**IP 주소 설정**
- 고정 IP 또는 유동 IP(DHCP 사용, 가정용)

**명령어**
- `ipconfig`: 내 컴퓨터의 IP, MAC 주소 확인
- `nslookup`: 도메인 이름의 IP 주소 확인
- `tracert`: 목적지까지의 경로 추적

### 4.2. 주소 체계
**서브넷**(Subnet)
- 네트워크를 작게 나눈 단위
- 서브넷 마스크로 구분

**게이트웨이**
- 외부 네트워크로 나가는 출구

## 5. 인터넷 개요
[[인터넷]]

### 5.1. 인터넷의 역사
- **시초**: 1969년 **ARPANET** (미국 국방성, 냉전 산물)
- **발전**: 1983년 TCP/IP 채택, 1980년대 NSFNET(연구용) 등장
- **한국의 인터넷**: 1982년 SDN 개통(전길남 교수, 세계 2번째), 1994년 상용 서비스(KORNet) 시작

### 5.2. 인터넷의 특징
- 세계 최대의 통신망, 네트워크의 네트워크
- 개방형 프로토콜(TCP/IP) 사용

## 6. 인터넷 동작원리
### 6.1. TCP/IP 4계층 모델
**응용 계층**
- **역할**: 사용자가 사용하는 소프트웨어(웹 브라우저, 이메일 프로그램 등)와 네트워크를 연결해주는 단계이다.
- **특징**: 사람이 이해할 수 있는 데이터를 생성하고, 특정 서비스에 맞는 형식을 정한다.

**전송 계층**
- **역할**: 통신 노드(컴퓨터) 간의 **연결을 제어**하고 데이터가 제대로 전달되도록 보장한다.
- **특징**: 데이터를 적절한 크기로 나누고, 받는 쪽에서 다시 합칠 수 있도록 번호를 붙인다.

**인터넷 계층**
- **역할**: 데이터를 목적지 IP 주소까지 **가장 효율적인 경로로 전달**하는 역할을 한다. (라우팅)
- **특징**: 데이터에 IP 주소라는 라벨을 붙여 패킷(Packet) 단위로 보낸다.

**네트워크 액세스 계층**
- **역할**: 데이터를 실제 **물리적인 신호**(전기 신호, 광신호 등)로 바꾸어 전선이나 무선망을 통해 전달한다.
- **특징**: 하드웨어적인 부분(랜카드, 케이블)과 관련된 계층이다. MAC 주소를 사용해 데이터를 전달한다.

## 7. 월드와이드웹(WWW)
### 7.1. 웹(Web)의 개요
**정의**
- 인터넷 기반의 거미줄처럼 연결된 정보망

**구성 요소**
- 하이퍼텍스트(Hypertext)
- HTML(언어)
- HTTP(프로토콜)
- URL(주소)

**구조**
- 클라이언트(요청, 브라우저) ↔ 서버(응답, 웹 서버)

### 7.2. 웹 브라우저와 웹 서버
**웹 브라우저**
- HTML을 해석해 보여줌
- 크롬(Chrome, 현재 점유율 1위), 엣지, 사파리 등

**웹 서버**
- 클라이언트의 요청에 응답(파일 전송)
- 아파치(Apache), IIS, NGINX 등

## 8. 웹 프로그래밍
### 8.1. 웹 관련 언어 및 기술
**HTML**
- 웹 페이지의 구조와 내용 정의
- (HTML5는 멀티미디어 기능 강화)

**XML**
- 데이터의 구조와 의미를 정의(확장성)

**스크립트 언어**
- **JavaScript**: 웹 페이지의 동적 동작 구현(클라이언트 측)

**웹 표준**
- W3C 가이드라인 준수(브라우저 종류에 상관없이 동일한 결과)

### 8.2. 검색 엔진
**원리**
- 크롤링(정보 수집)
- → 인덱싱(색인 DB 저장)
- → 검색(알고리즘 기반 결과 출력)

### 8.3. 웹의 진화
**Web 1.0**
- 읽기 중심
- 단방향 정보 제공

**Web 2.0**
- **참여, 공유, 개방**
- 양방향 소통(블로그, 위키백과, RSS)

**Web 3.0**
- **시맨틱 웹(Semantic Web)**
- 컴퓨터가 의미를 이해하고 추론하여 맞춤형 정보 제공(지능형 웹)
