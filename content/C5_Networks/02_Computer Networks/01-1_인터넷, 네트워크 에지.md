## 요약
1. **네트워크 에지**
	- 응용 프로그램을 실행하고 데이터를 송수신하는 호스트

2. **접속 네트워크**
	- 호스트와 에지 라우터의 연결
	- 대역폭(전송률)
	- 공유 자원, 전용 자원
	- 유도(유선), 비유도(무선)

3. **네트워크 코어**
	- 상호 연결된 라우터들을 통한 패킷 전달
	- 라우팅: 전체 경로 결정
	- 포워딩: 개별 라우터에서 다음 출력 링크로 전달

## 1. 전체 구조부터 이해하기
**인터넷**
- **여러 네트워크가 서로 연결**된 ‘네트워크의 네트워크’이다.
- 응용 프로그램이 데이터를 주고받게 하는 **기반**이다.

```
호스트(클라이언트·서버)
        ↕
접속 네트워크(가정·학교·기업·무선)
        ↕
에지 라우터
        ↕
네트워크 코어(상호 연결된 라우터들)
        ↕
다른 접속 네트워크와 호스트
```

- **호스트**: 통신의 출발점과 도착점이 되는 장치
- **접속 네트워크**: 호스트를 에지 라우터에 연결하는 네트워크
- **코어**: 여러 네트워크 사이에서 패킷을 전달하는 중심부
- **링크와 물리 매체**: 장치 사이에서 신호가 전달되는 통로
- **프로토콜**: 장치들이 통신할 때 따르는 규칙

> 호스트가 데이터를 만들고,
> 접속망을 거쳐 코어로 보내며,
> 통신 규칙은 프로토콜이 정한다.

## 2. 인터넷이란 무엇인가?
### 2.1. 구성 요소 관점: 무엇으로 이루어져 있는가?
| 구성 요소             | 의미                                     | 예시·역할                      |
| ----------------- | -------------------------------------- | -------------------------- |
| **호스트 또는 종단 시스템** | 네트워크에 연결되어 응용 프로그램을 실행하는 장치            | PC, 서버, 스마트폰, 노트북          |
| **통신 링크**         | 장치 사이에서 데이터를 전달하는 연결                   | 광 케이블, 동축 케이블, 전파, 위성 통신   |
| 패킷                | 전송을 위해 나눈 데이터 묶음                       | 메시지를 작은 단위로 나누어 전달         |
| **패킷 교환 장치**      | 패킷을 다음 연결로 전달하는 장치                     | 라우터, 스위치                   |
| ISP               | Internet Service Provider, 인터넷 서비스 제공자 | 접속 서비스를 제공하고 다른 ISP와 연결    |
| 프로토콜              | 메시지 송수신을 제어하는 규칙                       | TCP, IP, HTTP, IEEE 802.11 |

인터넷 연결 장치
- **여러 종류의 장치가 네트워크를 통해 정보를 주고받을 수 있다.**
- 컴퓨터에 한정되지 않는다. 냉장고, 디지털 액자, 에너지 사용량 측정기, 센서가 장착된 매트리스 등도 예로 든다.

### 2.2. 서비스 관점: 무엇을 제공하는가?
인터넷
- 웹, 인터넷 전화(VoIP), 이메일, 게임, 전자상거래, SNS 같은 **응용 서비스를 실행할 수 있게 하는 하부 구조**이다.
- 또한 응용 프로그램이 데이터를 송수신할 수 있도록 **프로그램 인터페이스**를 제공한다.
- 이를 통해 응용 프로그램은 통신 채널과 필요한 서비스 옵션을 이용한다.

| 관점 | 중심 질문 | 답의 핵심 |
|---|---|---|
| 구성 요소 관점 | 무엇으로 구성되는가? | 호스트, 링크, 패킷 교환 장치, ISP, 프로토콜 |
| 서비스 관점 | 무엇을 가능하게 하는가? | 응용 프로그램의 데이터 송수신과 서비스 실행 |

### 2.3. 인터넷 표준
**IETF** (Internet Engineering Task Force)
- 인터넷 기술과 표준을 논의·개발하는 **조직**

**RFC** (Request for Comments)
- 인터넷 기술과 규약 등을 설명하는 **문서** 체계

## 3. 프로토콜: 통신 규칙
**프로토콜**
- 통신 개체 사이에서 교환되는 메시지의 ==형식==과 ==순서==,
- 메시지 송수신 및 사건 발생 시의 ==행동==을 정의한다.

요소는 세 가지다.
1. **형식**: 어떤 모양과 내용의 메시지를 보내는가?
2. **순서**: 어떤 메시지 다음에 어떤 메시지를 보내는가?
3. **행동**: 메시지를 받거나 특정 사건이 발생하면 무엇을 하는가?

## 4. 네트워크 에지·접속 네트워크·코어
| 구분                              | 핵심 역할                  | 구성·예시            |
| ------------------------------- | ---------------------- | ---------------- |
| ==네트워크 에지==<br>(network edge)   | 응용 프로그램을 실행하고 데이터를 송수신 | 호스트(클라이언트, 서버 등) |
| ==접속 네트워크==<br>(access network) | 호스트를 에지 라우터와 연결        | 가정망, 기관망, 무선 접속망 |
| ==네트워크 코어==<br>(network core)   | 네트워크 사이에서 패킷을 전달       | 상호 연결된 라우터들      |

서버가 데이터센터에 위치하고, 사용자가 클라이언트 장치를 이용하는 전형적인 구성을 제시한다.

### 4.1. 접속 네트워크를 비교할 때 볼 것
*대역폭 (Bandwidth)*
- bps (bits per second): 직렬 통신
- BPS 또는 B/s (Bytes per second): 병렬 통신

**전송률**
- 초당 얼마나 많은 비트를 전송할 수 있는가?

**공유 여부**
- 여러 사용자가 같은 통신 자원을 공유하는가, 특정 구간을 전용으로 사용하는가?
- **공유·전용은 구간을 정해서 판단한다.** 특정 접속 구간이 전용이라고 해서 인터넷의 전체 경로가 전용이라는 뜻은 아니다.

**접속 방식**
- 유선인가, 무선인가?

## 5. 주요 접속 네트워크
### 5.1. 가정 접속 네트워크
```
유선 장치 ── 이더넷 ──┐
                       ├── 라우터 ── 모뎀 ── ISP
무선 장치 ── Wi-Fi AP ─┘
```

| 장치·기능            | 이해할 역할                    |
| ---------------- | ------------------------- |
| 모뎀               | 케이블·DSL 등 외부 접속 회선에 연결    |
| 라우터              | 가정망과 외부 네트워크 사이에서 패킷 전달   |
| AP(Access Point) | 무선 장치가 네트워크에 접속하는 지점      |
| 방화벽·NAT          | 강의 그림에 함께 표시된 가정용 네트워크 기능 |
이 기능들은 하나의 장치에 통합되기도 한다. **하나의 기기에 들어 있어도 역할은 구분해서 이해한다.**

### 5.2. 무선 접속 네트워크
| 구분       | 무선 LAN(Wi-Fi)      | 광역 무선 접속(셀룰러)     |
| -------- | ------------------ | ----------------- |
| 사용 범위    | 건물 내부 등 비교적 좁은 범위  | 이동통신사가 제공하는 넓은 범위 |
| 연결 지점    | AP                 | 이동통신 기지국          |
| 자료의 기술 예 | IEEE ==802.11== 계열 | 3G, 4G, LTE, 5G   |
| 자료의 범위 예 | 약 100 ft           | 수십 km 규모          |

**공통점**: 여러 종단 시스템이 무선 통신 자원을 공유한다.

**구분 포인트**: 둘 다 무선이지만, 접속 범위와 연결 인프라가 다르다.

### 5.3. 기관 접속 네트워크: 이더넷
기업이나 대학의 전형적인 연결 구조는 다음과 같다.
```
호스트 → 이더넷 스위치 → 기관 라우터 → ISP
```

- 종단 시스템은 이더넷 스위치에 **1:1로 연결**된다.
- 기관 내부에는 메일·웹 서버 등이 있을 수 있다.
- 자료의 전송률 예: **10 Mbps, 100 Mbps, 1 Gbps, 10 Gbps**.

## 6. 패킷 송신과 전송 지연
### 6.1. 호스트의 송신 과정
1. 응용 프로그램으로부터 전송할 메시지를 받는다.
2. 메시지를 패킷 단위로 나눈다.
3. 패킷을 전송률 `R`인 링크로 내보낸다.

패킷 길이를 `L`비트로 두고 전송 시간을 계산한다.

### 6.2. 전송 지연 공식
$$d_{trans} = \frac{L}{R}$$
- $d_{trans}$: 전송 지연 (초)
	- 패킷의 모든 비트를 링크로 밀어 넣는 데 걸리는 시간
- $L$ (Packet Length): 패킷의 길이 (bits)
- $R$ (Transmission Rate; Bandwidth): 링크의 전송률 (bits/sec)

### 6.3. 단위 변환
| 단위           | 의미                 |
| ------------ | ------------------ |
| bit, b       | 비트                 |
| byte, B      | 바이트. `1 B = 8 bit` |
| bps 또는 bit/s | 초당 비트 수            |
| B/s          | 초당 바이트 수           |
| Mbps         | 초당 `10^6`비트        |
| Gbps         | 초당 `10^9`비트        |

강의는 비트/초와 바이트/초를 `bps`와 `BPS`로 대비한다.
계산에서는 **bit/s와 B/s처럼 단위를 명확히 적는 습관**이 좋다.

### 6.4. 계산 예제
**문제**: 1,500바이트 패킷을 100 Mbps 링크로 전송할 때 전송 지연은?

```
① 패킷 길이를 비트로 변환
   L = 1,500 × 8 = 12,000 bit

② 전송률을 bit/s로 변환
   R = 100 × 10^6 = 100,000,000 bit/s

③ 공식 적용
   d_trans = 12,000 / 100,000,000
           = 0.00012 s
           = 0.12 ms
```

- 패킷 길이 `L`이 2배이면 전송 지연도 **2배**다.
- 전송률 `R`이 2배이면 전송 지연은 **절반**이다.
- 바이트를 비트로 바꾸지 않으면 계산값에 **8배의 차이**가 생긴다.

## 7. 물리 매체
**물리 매체는 송신 장치와 수신 장치 사이에서 신호를 전달하는 매체다.**

| 구분         | 전달 방식                   | 예시                    |
| ---------- | ----------------------- | --------------------- |
| **유도 매체**  | 케이블 같은 물리적 경로를 따라 신호 전달 | 꼬임 쌍동선, 동축 케이블, 광 케이블 |
| **비유도 매체** | 공간을 통해 전자기파 전달          | Wi-Fi, 셀룰러, 위성 통신     |

> **매체와 경로에 따라 지연 특성이 달라질 수 있다.**

### 7.1. 유도 매체
| 매체         | 구조·전달 방식           | 핵심 특징                         | 예시                                     |
| ---------- | ------------------ | ----------------------------- | -------------------------------------- |
| **꼬임 쌍동선** | 절연된 두 구리선을 나선형으로 꼼 | 이더넷에 사용                       | Cat 5: 100 Mbps·1 Gbps, Cat 6: 10 Gbps |
| **동축 케이블** | 동심원 구조의 두 도체       | 양방향 전송, 여러 주파수 채널 사용, HFC에 활용 | 별도 속도보다 구조와 다중 채널에 주목                  |
| **광 케이블**  | 빛의 펄스로 비트 전달       | 고속, 낮은 오류율, 전자기 간섭에 강함        | 10~100 Gbps                            |

위 속도 예시는 거리·규격·장비 등의 조건을 생략한 수치다.
매체의 절대적인 성능 한계로 해석하지 않는다.

### 7.2. 비유도 매체
| 매체         | 구조·전달 방식    | 핵심 특징                  | 예시                     |
| ---------- | ----------- | ---------------------- | ---------------------- |
| **라디오 채널** | 전자기파로 신호 전달 | 케이블 불필요, 반사·장애물·간섭의 영향 | Wi-Fi·셀룰러·위성 등 유형별로 다름 |

‘물리적인 매체 불필요’는 **장치 사이에 케이블을 설치하지 않아도 된다**는 의미로 이해한다.

무선 환경에서 신호에 영향을 주는 요인
- **반사**: 신호가 물체에 부딪혀 반사된다.
- **장애물**: 물체가 신호 전달을 방해한다.
- **간섭**: 다른 신호가 통신에 영향을 준다.

라디오 채널 유형
- 지상 마이크로파, 무선 LAN, 셀룰러
- 위성: 정지 위성, 저궤도 위성

## cf. 케이블·DSL과 주파수 분할
### 1. 주파수 분할 다중화(FDM)
> 같은 선을 사용하되, 주파수 구역을 나눈다.

**하나의 통신 매체에서 주파수 대역을 나누어 서로 다른 채널로 사용하는 방식**이다.
- 케이블망: TV와 데이터를 서로 다른 주파수 대역으로 전달한다.
- DSL: 음성과 데이터를 서로 다른 주파수 대역으로 전달한다.

### 2. 케이블망과 DSL 비교
| 항목          | 케이블 접속                          | DSL                                 |
| ----------- | ------------------------------- | ----------------------------------- |
| 명칭          | HFC: Hybrid Fiber Coax, 광동축 혼합망 | Digital Subscriber Line, 디지털 가입자 회선 |
| 매체          | 광 케이블과 동축 케이블                   | 기존 전화선                              |
| 사업자 측 장치    | 케이블 헤드엔드의 CMTS                  | 집중국의 DSLAM                          |
| 접속 구간       | 가정들이 헤드엔드까지 접속망 공유              | 가정에서 집중국까지 전용 회선                    |
| 주파수 분리      | TV·데이터                          | 음성·데이터                              |
| 자료의 다운로드 속도 | 최대 30 Mbps                      | 24~52 Mbps                          |
| 자료의 업로드 속도  | 최대 2 Mbps                       | 3.5~16 Mbps                         |

- **CMTS**: Cable Modem Termination System
- **DSLAM**: DSL Access Multiplexer
- **다운스트림**: 네트워크에서 사용자 쪽으로 전달
- **업스트림**: 사용자에서 네트워크 쪽으로 전달
- **비대칭**: 다운로드와 업로드 전송률이 서로 다름

DSL의 주파수 예: 음성 `0~4 kHz`, 데이터 `4~50 kHz` 및 `50 kHz~1 MHz`
세부 수치보다 **음성과 데이터를 대역별로 나눈다**는 원리를 먼저 이해한다.
