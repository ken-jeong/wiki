## HTTP 메서드
**GET** - 리소스 조회
- 서버에서 데이터를 가져올 때 (조회)

**POST** - 새 리소스 생성 / 데이터 처리 요청
- 새 글 작성, 로그인 등 데이터 제출

**PUT** - 리소스 전체 수정 또는 대체
- 리소스 전체를 새로운 내용으로 바꿀 때

**PATCH** - 리소스 일부 수정
- 특정 속성만 업데이트할 때

**DELETE** - 리소스 삭제
- 리소스를 제거할 때

| 메서드      | 용도                                                                 |
| -------- | ------------------------------------------------------------------ |
| **GET**  | 서버에 데이터 전송용<br>입력 내용이 URL 필드의 요청 라인에 `?` 뒤에 기술되어 전송됨               |
| **POST** | 사용자 입력용<br>폼 입력에 포함된 웹 페이지 수신<br>입력 내용이 **body(엔터티) 위치**에 포함되어 전송됨 |
| **HEAD** | GET 메서드에 기술한 URL에 대한 **헤더만** 요청                                    |
| **PUT**  | 서버에 파일 업로드 시 사용<br>기술된 경로의 파일 내용을 새로 대체함                           |
