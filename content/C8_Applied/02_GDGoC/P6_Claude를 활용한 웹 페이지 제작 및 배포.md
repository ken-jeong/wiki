- 5주차에 Vinsign으로 만든 UI 화면 초안을 바탕으로,
- Claude로 실제 접속 가능한 웹 페이지를 만들고,
- Netlify로 배포하는 실습

## 1. 학습 목표
- 웹 페이지의 기본 구조 이해
- Claude로 반응형 웹 페이지 코드 생성
- 생성한 페이지를 Netlify로 배포
- 최종 배포 링크를 과제로 제출

## 2. 웹 페이지 기본 구조
| 요소         | 역할                  |
| ---------- | ------------------- |
| HTML       | 화면에 무엇을 보여줄지 (구조)   |
| CSS        | 어떻게 예쁘게 보여줄지 (디자인)  |
| JavaScript | 눌렀을 때 어떻게 움직일지 (동작) |

## 3. 실습
### 3.1. 프롬프트 작성법
**어떤 서비스인지 / 어떤 화면을 원하는지 / 디자인 톤**을 구체적으로 적는 것이 핵심이다.

- **기본 형식**
> [서비스 아이디어]를 소개하는 반응형 웹 페이지를 만들어줘.
> 주요 기능은 [핵심 기능]이야. 디자인은 [톤앤매너]로 해줘.
> HTML, CSS, JavaScript를 한 파일로 작성해줘.

### 3.2. 실습 진행 순서
- Claude 접속 → 아이디어·기능 정리 → 프롬프트 입력 → 코드 복사 → `index.html` 생성 후 붙여넣기 → 브라우저로 확인 → (필요시) 수정 요청 → Netlify 업로드 → 링크 제출

### 3.3. 수정 요청 예시
디자인(흰 배경·포인트 컬러·둥근 모서리), 모바일 반응형(카드 세로 정렬), 기능 추가(핵심 기능 카드), 문구 톤 조정 등을 자연어로 추가 요청할 수 있습니다.

### 3.4. Netlify 배포
- 가장 간단한 **드래그 앤 드롭** 방식
	1. Netlify 접속 → 로그인
	2. `Add new site` / `Deploy manually`
	3. `index.html`이 든 폴더 업로드
	4. 생성된 웹 주소 확인 및 접속 테스트

- 주의
	- 파일명은 반드시 `index.html`
	- 파일 하나보다 **폴더째 업로드** 권장
	- 배포 후 링크 동작 확인 필수

## 4. 결과물 확인 기준
- 서비스 아이디어가 잘 드러나는가
- 핵심 기능 3~5개 포함
- 깔끔한 디자인
- 모바일에서 깨지지 않음
- 구성의 자연스러움
- 배포 링크 정상 작동
