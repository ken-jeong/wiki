## 1. 벡터의 개념과 표현
### 1.1. 스칼라와 벡터의 구분
- **스칼라 (Scalar)**
	- **크기**(magnitude)만으로 표현되는 양
	- 예: 압력·속력·질량·면적·부피

- **벡터 (Vector)**
	- **크기에 더해 방향**(direction)까지 가지는 양
	- 예: 속도·힘·가속도

### 1.2. 벡터를 보는 관점
#### (1) 기하학적 관점의 벡터
> 벡터를 **크기(길이)와 방향을 가진 화살표**로 본다.

- 화살표의 **시점**(Initial point; tail) $A$에서
- **종점**(Terminal point; head) $B$로 향하는
- 방향을 가진 선분을 **유향선분** $AB$, 벡터 $\vec{AB}$ 또는 $\vec{a}$

![[representation of vector.png]]

- 본질적 특징은 좌표계와 무관하게 벡터가 존재한다는 점이다.
	- 화살표는 평면 어디에 그려도 길이와 방향만 같으면 같은 벡터이다.
	- (위치 자유로움, free vector)
	
	- **벡터의 상등**(equality) 또는 **동치**(equivalent)
		- 두 벡터가 위치와 관계 없이 ==크기와 방향이 같아야 한다.==
		- → 즉 평행이동(translation)시킨 두 벡터는 서로 같다.

- 연산도 시각적으로 정의된다.
	- 덧셈
		- $\vec{AB}+\vec{BC}=\vec{AC}$
		- 삼각형의 법칙 (벡터의 상등을 이용하여, 한 화살표의 머리에 다른 화살표의 꼬리를 잇는 것)
		- 평행사변형의 법칙 (평행사변형의 대각선)
	- 벡터의 **뺄셈**(subtraction) 또는 차(difference)
		- $\vec{OA}-\vec{OB}=\vec{BA}$
		- 음의 벡터를 더한다.
	- 스칼라배
		- 스칼라 α가 양수이면 화살표를 같은 방향으로 늘이거나 줄이고,
		- 음수이면 반대 방향으로 뒤집는다.
	- [[08_벡터의 내적과 외적#(2) 대수적 관점의 내적|대수적 관점의 내적]]
	- [[08_벡터의 내적과 외적#(2) 대수적 관점의 외적|대수적 관점의 외적]]

- 장점은 직관적이라는 것, 한계는 차원이 높아지면 그릴 수 없다는 것이다.

#### (2) 대수적 관점의 벡터
> 벡터를 **순서 있는 성분들의 나열** $\vec{v}=(v_1, v_2, \dots, v_n)$로 본다.

- 결정적인 차이는 이 표현이 기저(좌표계) 선택에 의존한다는 점이다.
	- 같은 화살표라도 좌표축을 바꾸면 성분 값이 달라진다.

- 연산은 모두 성분 단위 계산이 된다.
	- 덧셈과 뺄셈
		- 대응하는 성분끼리 더하거나 빼서 계산한다.
		- $v+w = (v_1+w_1, ..., v_n+w_n)$
		- $v−w = (v_1−w_1, ..., v_n−w_n)$
	- 스칼라배
		- 벡터의 각 성분에 스칼라 α 곱하기
	- [[08_벡터의 내적과 외적#(1) 기하학적 관점의 내적|기하학적 관점의 내적]]
	- [[08_벡터의 내적과 외적#(1) 기하학적 관점의 외적|기하학적 관점의 외적]]

- 장점은 계산이 기계적으로 가능하고, 4차원 이상이나 추상 공간으로 자유롭게 일반화된다는 것이다.

### 1.3. 벡터의 크기(노름; norm)
- **벡터의 크기**
	- $\vec{AB}$의 크기 = 선분 $\overline{AB}$의 길이 = $|\vec{AB}|$ 혹은 $‖\vec{AB}‖$
	- 크기는 항상 $‖u‖≥0$이다. (영벡터일 때 0)

- **norm**
	- vector의 길이나 크기를 측정하는 방법

- 예
	- 평면에서 $u = (a, b)$이면, $‖u‖ = \sqrt{(a^2+b^2)}$ (피타고라스 정리에 따라 정의)
	- $a=\begin{bmatrix}1\\2\\3\end{bmatrix} → ‖a‖=\sqrt{1^2+2^2+3^2}$

|          종류           |                         정리                          |
| :-------------------: | :-------------------------------------------------: |
|   **Lp norm** (일반화)   | $(\|a_1\|^p+\|a_2\|^p+...+\|a_n\|^p)^{\frac{1}{p}}$ |
| **L1 norm** (맨해튼 거리)  | $(\|a_1\|^1+\|a_2\|^1+...+\|a_n\|^1)^{\frac{1}{1}}$ |
| **L2 norm** (유클리드 거리) |       $(a_1^2+a_2^2+...+a_n^2)^{\frac{1}{2}}$       |

### 1.4. 벡터의 평행
- **벡터의 평행**
	- 두 벡터 $\vec{a},\ \vec{b}$의 방향이 같거나 반대일 때 $\vec{a},\ \vec{b}$는 서로 평행하다고 한다.
	- 기호로는 $\vec{a}//\vec{b}$로 나타낸다. (단, $\vec{a}≠\vec{0},\ \vec{b}≠\vec{0}$)

- **두 벡터의 평행 조건**
	- $\vec{a}//\vec{b}⇔\vec{a}=k·\vec{b}$ (단, $\vec{a}≠\vec{0},\ \vec{b}≠\vec{0}$, k≠0인 실수)

### 1.5. 기타 벡터
- **영벡터**(zero vector; $\vec{0}$)
	- 모든 성분이 0인 벡터
	- 시점과 종점이 일치하는 벡터
	- 크기는 0이 된다. ($|\vec{0}|=0$)
	- $u + 0 = u$, $u + (−1)u = 0$이 성립한다.

- **역벡터**(음의 벡터, negative vector; $-\vec{a}$)
	- 벡터 $\vec{a}$와 크기가 같고 ($|-\vec{a}|=|\vec{a}|$)
	- 방향이 반대인 벡터
	- (더했을 때 합이 영벡터가 되는 벡터)

#### (1) 위치벡터
- 원점에서 (x, y, z)까지 향하는 벡터를 **위치벡터**라 한다.
	- n차원으로 확장하면 행벡터 u = (x₁, ..., xₙ) 또는 열벡터 형태로 나타낸다.
	- 평면 벡터는 2×1 행렬이다.

![[representation of component vector.png]]

- **벡터**
	- $\vec{v}=a\vec{i}+b\vec{j}$ ($R^2$에서의 벡터를 표준기저벡터의 선형결합으로 표현)
	- **위치벡터**(position vector): 벡터의 시점을 원점(O)으로 옮긴 벡터 ($\vec{AB}=\vec{OC}$)
	- **성분벡터**(component vector): $\vec{v}=\langle a, b \rangle$으로 표현
	- **좌표벡터**: $[a\ b]^T$ (좌표를 열벡터로 표현)
	- **기저벡터**: $\vec{i},\ \vec{j}$ ($R^2$에서의 표준기저벡터)

- **위치벡터와 성분표시법의 관계**
	- 벡터의 구별 기준은 오직 벡터의 시점을 원점으로 옮겼을 때의 종점의 위치다.
	- 이 때 종점의 좌표만 알아도 무수히 많은 벡터들을 쉽게 구별할 수 있다.
	- → ==벡터를 좌표 성분으로 표기할 수 있는 근거 마련==

- 또한 이것을 n차원 공간인 $R^n$까지 확장하면 벡터 u는
	- 행벡터 표기 방식: $u=(x_1, x_2, ..., x_n)$
	- 열벡터 표기 방식: $u=\begin{bmatrix}x_1\\x_2\\...\\x_n\end{bmatrix}$

## 2. 벡터의 연산
### 2.1. 벡터의 덧셈과 뺄셈
- **벡터의 연산법칙**
	- 덧셈 교환법칙(commutative property) 성립
		- $u + v = v + u$
	- 덧셈 결합법칙(associative property) 성립
		- $u + (v + w) = (u + v) + w$
	- 벡터의 덧셈에 대한 항등원 $\vec{0}$
		- $u + 0 = u$
	- 벡터 $\vec{a}$의 덧셈대 한 역원 $-\vec{a}$
		- $u + (−u) = 0$

### 2.2. 벡터의 스칼라곱
- (영벡터 0과 스칼라 α, β에 대하여)
	1. α(u + v) = αu + αv
	2. (α + β)u = αu + βu
	3. α(βu) = (αβ)u
	4. 1u = u (곱셈 항등원)
	5. 0u = 0 (영벡터)

- 벡터의 **스칼라곱**(실수배)
	- 스칼라×벡터 → (실수 배) 벡터
	- 크기는 |α|·‖u‖가 된다.
	
	- 일반적인 대수적인 성질 성립
	- 결합법칙 성립
	- 좌분배법칙, 우분배법칙 성립

## 3. 벡터의 성분
- 예: 벡터 (3, 4)
	- **크기**: $|\vec{v}|=\sqrt{9+16}=\sqrt{25}=5$
	- **방향**: $θ=\tan^{-1}(\frac{4}{3})$
	- **단위벡터**: 원래 벡터/크기

### 3.1. 단위벡터
- **단위벡터**(unit vector)
	- 크기가 1인 벡터
	- 정의: $\hat{v}=\frac{\vec{v}}{|\vec{v}|}$

- **단위좌표벡터**
	- 임의의 벡터를 그 크기로 나누면 (1/‖v‖)v로 같은 방향의 단위벡터를 얻는다.
	- 좌표축 방향의 특별한 단위벡터 i, j (3차원은 i, j, k)를 단위좌표벡터 또는 기저벡터라고 한다.

#### (1) 유클리드 공간 $R^2$
- **단위벡터**: {(1, 0), (0, 1)}이 종점인 위치벡터
- **평면벡터**: 단위벡터의 실수 배들을 결합하여 평면상의 모든 벡터를 만들 수 있다.

![[representation of unit vector 1.png]]

- **평면벡터의 norm**: $|\vec{p}|=\sqrt{p_1^2+p_2^2}$

- **벡터의 성분(2차원)의 덧셈과 뺄셈**
	- 그림을 그리는 대신, 벡터의 성분끼리 대수적으로 덧셈과 뺄셈을 할 수 있다.
	- $\vec{OQ}+\vec{OP}=(p_1+q_1,\ p_2+q_2)$
	- $\vec{OP}-\vec{OQ}=(p_1-q_1,\ p_2-q_2)=\vec{QP}$

- **평면벡터의 실수배**

#### (2) 유클리드 공간 $R^3$
- **단위벡터**: {(1, 0, 0), (0, 1, 0), (0, 0, 1)}이 종점인 위치벡터
- **공간벡터**: 단위벡터의 실수 배들을 결합하여 공간상의 모든 벡터를 만들 수 있다.

![[representation of unit vector 2.png]]

- **공간벡터의 norm**: $|\vec{p}|=\sqrt{p_1^2+p_2^2+p_3^2}$

- **공간벡터의 실수배**

### 3.2. 방향비(방향 코사인)
- **방향비**(방향 코사인)
	- $cosα=\frac{d_1}{|\vec{d}|},\ cosβ=\frac{d_2}{|\vec{d}|},\ cosγ=\frac{d_3}{|\vec{d}|}$
